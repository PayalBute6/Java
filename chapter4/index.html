Chapter 4: Exception and File Handling

4.1 Dealing with Errors

1. What is an error?

An error is a problem that occurs in a program and prevents it from working as expected.

For example, a program may contain incorrect syntax, attempt an invalid operation, or produce an incorrect result.

There are three common categories of programming errors:

Type Meaning Example
Compile-time error Detected by the compiler before running the program. Missing semicolon, misspelled keyword.
Runtime error Occurs while the program is executing. Dividing an integer by zero (10 / 0).
Logical error The program runs but produces the wrong result. Using a - b instead of a + b.

2. Examples of errors

Compile-time error

class Demo {
    public static void main(String[] args) {
        System.out.println("Hello")
    }
}

The semicolon is missing after the println() statement, so the program will not compile.

Runtime error

class Demo {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;
        System.out.println(a / b);
    }
}

Output: The program throws an ArithmeticException because integer division by zero is invalid.

Logical error

class Demo {
    public static void main(String[] args) {
        int a = 10, b = 5;
        System.out.println(a - b);
    }
}

Output:

5

If the requirement was to add the numbers, the program is logically incorrect even though it compiles and runs.

3. What is an exception?

An exception is an event that occurs during program execution and disrupts the normal flow of instructions.

Examples include:

  • Dividing an integer by zero.
  • Accessing an invalid array index.
  • Trying to open a file that does not exist.
  • Attempting to use a method on a null reference.

4. What is exception handling?

Exception handling is a mechanism used to detect and handle exceptional conditions so that the program can respond appropriately and continue executing without abruptly crashing.

Java provides five important keywords:

Keyword Purpose
try Encloses code that may throw an exception.
catch Handles a matching exception.
finally Runs after try/catch in ordinary control flow, whether or not an exception occurred.
throw Explicitly throws an exception object.
throws Declares exceptions that a method or constructor may pass to its caller.

5. Simple exception-handling program

class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;
            System.out.println(a / b);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero.");
        }

        System.out.println("Program continues.");
    }
}

Output:

Cannot divide by zero.
Program continues.

Explanation: The division causes an ArithmeticException. The catch block handles it, allowing execution to continue with the statement after the try-catch structure.

Exam points:
  • Exception handling helps a program respond to runtime problems.
  • try and catch are commonly used together.
  • throw throws an exception; throws declares it.
  • Logical errors are not automatically handled by Java's exception mechanism.

4.2 Exception Class

1. Exception hierarchy

Java's exception hierarchy begins with the Throwable class under java.lang.Object. The diagram below illustrates the complete hierarchy of Java exceptions and errors:

  • Throwable is the superclass of Error and Exception.
  • Error represents serious problems such as OutOfMemoryError (usually non-recoverable).
  • Exception represents conditions that an application can handle.
  • RuntimeException is a subclass of Exception and represents unchecked exceptions caused by programming defects.

2. Common exception classes

Exception When it occurs
ArithmeticException An invalid arithmetic operation, such as integer division by zero.
ArrayIndexOutOfBoundsException An array index is outside the valid range (< 0 or ≥ array length).
NullPointerException Code tries to use a null reference in an operation that requires an object.
NumberFormatException A string cannot be converted to the requested numeric type (e.g., Integer.parseInt("abc")).
FileNotFoundException A requested file cannot be opened because it does not exist.
IOException A general input/output operation fails.

3. Exception object and its methods

When an exception occurs, Java creates or receives an exception object containing information about the problem.

Useful methods include:

  • getMessage() — returns the detail message, if one was provided.
  • toString() — returns a textual representation of the exception (class name + message).
  • printStackTrace() — prints information showing the stack trace and where the exception occurred.

Example:

class Demo {
    public static void main(String[] args) {
        try {
            int n = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
            System.out.println(e.toString());
            e.printStackTrace();
        }
    }
}

The first two statements show the exception's message and type; the last prints diagnostic stack information showing the file name and line number.

4.2.1 Checked and Unchecked Exceptions

Checked exceptions

Checked exceptions are checked by the compiler. A method must handle them using try-catch or declare them using throws, unless they are handled at a higher level.

Examples: IOException, FileNotFoundException, SQLException.

Unchecked exceptions

Unchecked exceptions are not required to be caught or declared by the compiler. These include RuntimeException and its subclasses.

Examples: ArithmeticException, NullPointerException, ArrayIndexOutOfBoundsException.

Difference between checked and unchecked exceptions

Checked Unchecked
Compiler requires handling (try-catch) or declaration (throws). Compiler does not require handling or declaration.
Usually subclasses of Exception other than RuntimeException. RuntimeException and its subclasses.
Example: IOException, FileNotFoundException. Example: ArithmeticException, NullPointerException.

Example of a checked exception

import java.io.FileReader;
import java.io.IOException;

class CheckedDemo {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("data.txt");
            fr.close();
            System.out.println("File opened successfully.");
        } catch (IOException e) {
            System.out.println("File operation failed.");
        }
    }
}

If the file is missing or a file operation fails, the catch block handles the IOException or its subclass.

Example of an unchecked exception

class UncheckedDemo {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;

        try {
            System.out.println(a / b);
        } catch (ArithmeticException e) {
            System.out.println("Division by zero is not allowed.");
        }
    }
}

Output:

Division by zero is not allowed.

4.2.2 Logger Class

1. What is a Logger?

The Logger class belongs to the java.util.logging package. It is used to record messages about program execution, warnings, and errors.

Logging helps programmers understand what happened when a program was running.

Import statements:

import java.util.logging.Logger;
import java.util.logging.Level;

2. Common logging levels

Level Purpose
Level.SEVERE Serious failures.
Level.WARNING Potential problems.
Level.INFO General information.
Level.FINE Detailed debugging information.

3. Example program

import java.util.logging.Logger;
import java.util.logging.Level;

class LoggerDemo {
    private static final Logger log =
        Logger.getLogger(LoggerDemo.class.getName());

    public static void main(String[] args) {
        log.info("Program started.");

        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            log.log(Level.SEVERE, "Division failed.", e);
        }

        log.info("Program finished.");
    }
}

Explanation:

  • Logger.getLogger() obtains a logger instance for the class.
  • log.info() records an informational message.
  • log.log(Level.SEVERE, ..., e) records a serious problem along with exception details.
Exam point: System.out.println() displays simple console output, whereas a logger records diagnostic messages with timestamp, class, and specified log levels.

4.2.3 Catching Exceptions

An exception can be caught by placing potentially failing code inside a try block and providing a suitable catch block.

Syntax

try {
    // Code that may cause an exception
} catch (ExceptionType e) {
    // Exception-handling code
}

Example

class CatchDemo {
    public static void main(String[] args) {
        try {
            int a = 20;
            int b = 0;
            int c = a / b;
            System.out.println(c);
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error occurred.");
        }

        System.out.println("End of program.");
    }
}

Output:

Arithmetic error occurred.
End of program.

Role of finally

The finally block is commonly used for cleanup, such as closing resources.

class FinallyDemo {
    public static void main(String[] args) {
        try {
            int a = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Exception handled.");
        } finally {
            System.out.println("Finally block executed.");
        }
    }
}

Output:

Exception handled.
Finally block executed.

The finally block normally executes whether or not an exception occurs. It may not execute if the JVM terminates abruptly (e.g. System.exit(0)).

4.2.4 Multiple Catch Block

Definition

A multiple catch structure has more than one catch block associated with a single try block. Each catch handles a different type of exception.

Syntax

try {
    // Risky code
} catch (ArithmeticException e) {
    // Handle arithmetic exception
} catch (ArrayIndexOutOfBoundsException e) {
    // Handle array exception
} catch (Exception e) {
    // Handle other matching exceptions
}

Important: A general exception such as Exception must come after its more specific subclasses. Otherwise, the later catch block will be unreachable and cause a compile-time error.

Example program

class MultipleCatchDemo {
    public static void main(String[] args) {
        int choice = 2;

        try {
            switch (choice) {
                case 1:
                    System.out.println(10 / 0);
                    break;

                case 2:
                    int arr[] = {10, 20, 30};
                    System.out.println(arr[5]);
                    break;

                default:
                    System.out.println("Valid choice.");
            }
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic exception occurred.");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid array index.");
        }

        System.out.println("Program completed.");
    }
}

Output:

Invalid array index.
Program completed.

The value of choice is 2, so the array exception occurs and is handled by the second catch block.

Difference: Single catch and multiple catch

Single catch Multiple catch
One catch block handles a matching exception. Several catch blocks can handle different exception types.
Suitable for a simple exception-handling case. Suitable when different failures require different responses.

4.2.5 Nested try Block

Definition

A nested try block is a try block placed inside another try block.

It is useful when separate sections of code require separate exception handling.

Example

class NestedTryDemo {
    public static void main(String[] args) {
        try {
            System.out.println("Outer try started.");

            try {
                int a = 10 / 0;
            } catch (ArithmeticException e) {
                System.out.println("Division by zero.");
            }

            int arr[] = {10, 20, 30};
            System.out.println(arr[5]);

        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid array index.");
        }

        System.out.println("Program completed.");
    }
}

Output:

Outer try started.
Division by zero.
Invalid array index.
Program completed.

Explanation

  1. The outer try starts.
  2. The inner try attempts division by zero.
  3. The inner catch handles the arithmetic exception.
  4. Execution continues inside the outer try.
  5. Accessing arr[5] causes an array-index exception.
  6. The outer catch handles that exception.

4.2.6 Creating User-Defined Exception

A user-defined exception is an exception class created by the programmer to represent a specific application rule.

Steps

  1. Create a class for the exception.
  2. Extend Exception for a checked exception.
  3. Define a constructor for the message.
  4. Use throw to throw an exception object.
  5. Use throws to declare the checked exception.
  6. Handle it using try-catch.

Example: Driver age validation

class AgeException extends Exception {
    AgeException(String msg) {
        super(msg);
    }
}

class Driver {
    int license_no, age;
    String name, address;

    Driver(int l, String n, String addr, int a)
            throws AgeException {

        if (a < 18) {
            throw new AgeException("Age is below 18 years");
        }

        license_no = l;
        name = n;
        address = addr;
        age = a;

        System.out.println(
            "Driver " + name + " created successfully."
        );
    }
}

public class Main {
    public static void main(String[] args) {
        try {
            Driver d1 =
                new Driver(123, "Raju", "Pune", 16);
        } catch (AgeException e) {
            System.out.println(
                "Exception: " + e.getMessage()
            );
        }
    }
}

Output:

Exception: Age is below 18 years

Important keywords

  • extends Exception: creates a checked custom exception.
  • super(msg): passes the message to the superclass constructor.
  • throw: explicitly throws the exception object.
  • throws: declares a possible exception in the constructor or method.
  • getMessage(): returns the exception message.

Part II — File Handling

4.3 Introduction to Files and Streams

1. What is a file?

A file is a named location used to store related information permanently on a storage device.

Examples: student.txt, marks.txt, photo.jpg.

A file allows information to remain available even after a program terminates.

2. What is file handling?

File handling is the process of creating, reading, writing, appending, and deleting files through a program.

Java provides many file-handling classes in the java.io package.

3. What is a stream?

A stream is a sequence or flow of data between a source and a destination.

  • An input stream reads data from a source into memory.
  • An output stream writes data from memory to a destination.

Examples of sources and destinations include files, consoles, arrays, and sockets.

4. Sequential and random access

Sequential access: Data is processed in sequence, usually from the beginning towards the end.

Random access: Data can be accessed at a specific position using a file pointer. Java provides RandomAccessFile for random access.

5. File class

The File class represents a file or directory path. It can be used to inspect and manage file-system entries.

import java.io.File;

class FileClass {
    public static void main(String[] args) {
        File f = new File("sample.txt");

        System.out.println("Name = " + f.getName());
        System.out.println("Path = " + f.getPath());
        System.out.println("Is file = " + f.isFile());
        System.out.println("Size = " + f.length());
    }
}

The result depends on whether sample.txt exists and its contents.

Common File class methods

Method Purpose
getName() Returns the name of the file or directory.
getParent() Returns the parent path, or null.
length() Returns file size in bytes.
isFile() Checks whether the path represents a normal file.
getPath() Returns the path.
isDirectory() Checks whether the path represents a directory.
isAbsolute() Checks whether the path is absolute.
isHidden() Checks whether the file is hidden.
createNewFile() Creates a new empty file if absent.
delete() Attempts to delete a file or directory.

Creating a file

import java.io.File;
import java.io.IOException;

class CreateFileDemo {
    public static void main(String[] args) {
        try {
            File f = new File("test.txt");

            if (f.createNewFile()) {
                System.out.println("File created.");
            } else {
                System.out.println("File already exists.");
            }
        } catch (IOException e) {
            System.out.println("File creation failed.");
        }
    }
}

Deleting a file

import java.io.File;

class DeleteFileDemo {
    public static void main(String[] args) {
        File f = new File("test.txt");

        if (f.delete()) {
            System.out.println("File deleted.");
        } else {
            System.out.println("Unable to delete file.");
        }
    }
}

Note: Run deletion programs only on test files that you intend to remove.

4.5 Input-Output Streams

A stream in Java is a sequence of data flowing from a source to a destination.

1. Input Stream

An Input Stream is used to read data from a file, keyboard, or another source into a Java program.
In simple words: It brings data into the program.

2. Output Stream

An Output Stream is used to write data from a Java program to a file or another destination.
In simple words: It sends data out of the program.

3. Byte Streams

Byte Streams are used to read and write data in the form of bytes. They are mainly used for files such as images, audio, videos, and other binary files.
Main abstract classes: InputStream and OutputStream.
Examples: FileInputStream, FileOutputStream, BufferedInputStream, BufferedOutputStream.

4. Character Streams

Character Streams are used to read and write data in the form of characters. They are mainly used for handling text files.
Main abstract classes: Reader and Writer.
Examples: FileReader, FileWriter, BufferedReader, BufferedWriter.

Standard streams

Stream Purpose
System.in Standard input, usually the keyboard.
System.out Standard output, usually the console.
System.err Standard error output.

4.5.1 InputStream

An Input Stream is used to read data from a file, keyboard, or another source into a Java program.
In simple words: It brings data into the program.

InputStream is an abstract class used to read raw bytes of data from a source.

Important methods

Method Purpose
read() Reads one byte; returns -1 at end of stream.
read(byte[] arr) Reads bytes into an array.
read(byte[] arr, int off, int len) Reads bytes into a selected array range.
available() Estimates bytes readable without blocking.
reset() Returns to a marked position if supported.
close() Closes the stream and releases system resources.

4.5.3 FileInputStream

FileInputStream is a Java class used to read data from a file in the form of bytes.

Example: Reading a file

Create abc.txt containing: Sachin is my favourite player

import java.io.*;

class SimpleRead {
    public static void main(String[] args) {
        try {
            FileInputStream fin =
                new FileInputStream("abc.txt");

            int i;

            while ((i = fin.read()) != -1) {
                System.out.print((char) i);
            }

            fin.close();
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}

Output:

Sachin is my favourite player

Explanation:

  • FileInputStream opens the file for reading.
  • read() returns one byte at a time as an integer.
  • -1 indicates the end of the stream (EOF).
  • close() closes the stream.

4.5.2 OutputStream

An Output Stream is used to write data from a Java program to a file or another destination.
In simple words: It sends data out of the program.

OutputStream is an abstract class used to write bytes to a destination.

Important methods

Method Purpose
write(int b) Writes a single byte.
write(byte[] arr) Writes an array of bytes.
write(byte[] arr, int off, int len) Writes part of a byte array.
flush() Forces buffered output to be passed to the underlying destination.
close() Closes the stream.

4.5.4 FileOutputStream

FileOutputStream is a Java class used to write data into a file in the form of bytes.

Example: Writing to a file

import java.io.*;

class WriteFileDemo {
    public static void main(String[] args) {
        try {
            FileOutputStream fout =
                new FileOutputStream("abc.txt");

            String s = "Sachin Tendulkar is my favourite player";
            byte[] b = s.getBytes();

            fout.write(b);
            fout.close();

            System.out.println("Successfully written.");
        } catch (IOException e) {
            System.out.println("File error.");
        }
    }
}

Output:

Successfully written.

The text is written into abc.txt.

Important: new FileOutputStream("abc.txt") overwrites existing contents. To append, pass true:

FileOutputStream fout = new FileOutputStream("abc.txt", true);

4.5.5 BufferedInputStream

BufferedInputStream is a Java class used to read bytes efficiently by temporarily storing data in a memory buffer.

Constructors

BufferedInputStream(InputStream in)
BufferedInputStream(InputStream in, int size)

4.5.6 BufferedOutputStream

BufferedOutputStream is a Java class used to write bytes efficiently by temporarily storing data in a memory buffer.

Example

import java.io.*;

class BufferedWriteDemo {
    public static void main(String[] args) {
        try {

4.5.7 DataInputStream

Data Streams: Data Streams are used to read and write Java primitive data types, such as integers, floating-point numbers, and booleans, in binary form.

DataInputStream is a Java class used to read primitive data types such as int, float, double, and boolean from an input stream.

Important methods

Method Purpose
readInt() Reads an integer (4 bytes).
readDouble() Reads a double (8 bytes).
readFloat() Reads a float (4 bytes).
readLong() Reads a long (8 bytes).
readBoolean() Reads a boolean (1 byte).
readChar() Reads a character (2 bytes).
readUTF() Reads a string in Java's modified UTF-8 format.

4.5.8 DataOutputStream

DataOutputStream is a Java class used to write primitive data types such as int, float, double, and boolean to an output stream.

Methods include: writeInt(), writeDouble(), writeFloat(), writeLong(), writeBoolean(), writeChar(), and writeUTF().

Complete example: Writing and reading data

import java.io.*;

class DataStreamDemo {
    public static void main(String[] args) {
        try {
            DataOutputStream out =
                new DataOutputStream(
                    new FileOutputStream("data.dat")
                );

            out.writeInt(101);
            out.writeDouble(85.5);
            out.writeUTF("Payal");
            out.close();

            DataInputStream in =
                new DataInputStream(
                    new FileInputStream("data.dat")
                );

            int id = in.readInt();
            double marks = in.readDouble();
            String name = in.readUTF();
            in.close();

            System.out.println("ID: " + id);
            System.out.println("Marks: " + marks);
            System.out.println("Name: " + name);

        } catch (IOException e) {
            System.out.println("File error.");
        }
    }
}

Output:

ID: 101
Marks: 85.5
Name: Payal

Important rule: Data must be read in the exact same order and with the exact same types in which it was written.

4.6 Reader and Writer

Character Streams are used to read and write data in the form of characters. They are mainly used for handling text files.

1. What is Reader?

Reader is an abstract class used for character-based input (16-bit characters). Subclasses include:

  • FileReader
  • BufferedReader
  • InputStreamReader
  • CharArrayReader
  • StringReader

2. What is Writer?

Writer is an abstract class used for character-based output. Subclasses include:

  • FileWriter
  • BufferedWriter
  • OutputStreamWriter
  • CharArrayWriter
  • StringWriter

Difference between Reader/Writer and InputStream/OutputStream

Reader and Writer InputStream and OutputStream
Character-oriented (16-bit). Byte-oriented (8-bit).
Suitable for text processing and Unicode. Suitable for raw bytes and binary data (images, audio).
Examples: FileReader, FileWriter. Examples: FileInputStream, FileOutputStream.

4.6.1 FileReader

FileReader is a Java class used to read characters from a text file.

Example: Reading a file

import java.io.*;

class FileReaderDemo {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("input.txt");

If input.txt contains Hello Java, the output is: Hello Java.

4.6.3 BufferedReader

BufferedReader is a Java class used to read text efficiently using a buffer. It can also read an entire line at a time.

Important methods

  • read() — reads one character.
  • readLine() — reads a line of text, or returns null at end of file.
  • close() — closes the reader.

Example: Reading line by line

import java.io.*;

class BufferedReaderDemo {
    public static void main(String[] args) {
        try {
            BufferedReader br =
                new BufferedReader(
                    new FileReader("input.txt")
                );

            String line;

            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }

            br.close();
        } catch (IOException e) {
            System.out.println("Unable to read file.");
        }
    }
}

If the file contains:

Welcome to Java
File handling is useful

The program will print each line as read.

4.6.4 BufferedWriter

BufferedWriter is a Java class used to write text efficiently using a buffer.

Important methods

  • write(String s) — writes a string.
  • newLine() — writes a platform-independent line separator.
  • flush() — flushes buffered characters.
  • close() — flushes and closes the writer.

Example

import java.io.*;

class BufferedWriterDemo {
    public static void main(String[] args) {
        try {
            BufferedWriter bw =
                new BufferedWriter(
                    new FileWriter("output.txt")
                );

            bw.write("Welcome to Java");
            bw.newLine();
            bw.write("Learn file handling");

            bw.close();

            System.out.println("File written successfully.");
        } catch (IOException e) {
            System.out.println("File error.");
        }
    }
}

Output:

File written successfully.

4.6.5 InputStreamReader

Conversion Streams: Conversion streams act as a bridge between byte streams and character streams.

InputStreamReader is a Java class used to convert byte data into character data while reading.

Example

import java.io.*;
import java.nio.charset.StandardCharsets;

class InputStreamReaderDemo {

    }
}

Additional Important Topic: RandomAccessFile

RandomAccessFile allows reading and writing at specific byte positions in a file using a movable file pointer.

Access modes

Mode Meaning
"r" Read-only mode.
"rw" Read and write mode.
"rws" Read and write, with content and metadata updates synchronously written.
"rwd" Read and write, with content updates synchronously written.

Important methods

  • seek(long pos) — moves the file pointer to a byte position.
  • read() — reads the next byte.
  • write(int b) — writes a byte.
  • length() — returns the file length.

Example

import java.io.*;

class RandomAccessDemo {
    public static void main(String[] args) {
        try (RandomAccessFile f =
                 new RandomAccessFile("sample.txt", "rw")) {

            f.writeUTF("Java Programming");

            f.seek(0);

            System.out.println(f.readUTF());

        } catch (IOException e) {
            System.out.println("File error.");
        }
    }
}

4. Viva Questions

  1. What is an exception?
    An exception is an abnormal event during program execution that disrupts normal instruction flow.
  2. What is exception handling?
    A mechanism to handle runtime errors so the program can respond properly without crashing.
  3. What is the purpose of finally?
    It executes cleanup code (like closing resources), running whether an exception occurred or not.
  4. What is the difference between throw and throws?
    throw explicitly throws an exception object; throws declares exceptions on a method signature.
  5. What is a user-defined exception?
    A custom exception class created by extending java.lang.Exception.
  6. What is a checked exception?
    An exception checked at compile-time that must be caught or declared.
  7. What is a stream?
    A sequence or flow of data between a source and a destination.
  8. What is the java.io package?
    A Java package containing classes for reading and writing data through streams and files.
  9. What is the difference between byte and character streams?
    Byte streams handle 8-bit bytes (binary data); character streams handle 16-bit Unicode characters (text).
  10. What is the use of FileInputStream?
    To read raw binary bytes from a file.
  11. What is the use of FileOutputStream?
    To write raw bytes to a file.
  12. Why do we use buffered streams?
    To improve efficiency by reducing direct disk read/write operations via an internal buffer.
  13. What is the use of readLine()?
    To read an entire line of text at once in BufferedReader.
  14. What is the purpose of DataInputStream?
    To read primitive data types (int, double, etc.) in binary format.
  15. What is the purpose of DataOutputStream?
    To write primitive data types in binary format.
  16. What is the use of RandomAccessFile?
    To read and write data at any byte position in a file using a movable file pointer.
  17. What is the purpose of InputStreamReader?
    To bridge a byte stream to a character stream by decoding bytes into characters.
  18. What is the purpose of OutputStreamWriter?
    To bridge a character stream to a byte stream by encoding characters into bytes.
  19. What happens when read() returns -1?
    It indicates the End of File (EOF).
  20. Why should a stream be closed after use?
    To flush data and free up operating system file resources and avoid memory leaks.
