Question 1: Define a custom exception class called `AgeException`. Write a Driver class with fields license_no, name, address, and age. If the age is below 18, throw the `AgeException`. Handle this exception in the `Main` class.
class AgeException extends Exception {
    AgeException(String msg) {
        super(msg);
    }
}
class Driver {
    int license_no, age;
    String name, address;
    Driver(int l, String n, String addr, int a) throws AgeException {
        if (a < 18) {
            throw new AgeException("Age is below 18 years");
        }
        license_no = l;
        name = n;
        address = addr;
        age = a;
        System.out.println("Driver " + name + " created successfully.");
    }
}
public class Main {
    public static void main(String[] args) {
        try {
            Driver d1 = new Driver(123, "Raju", "Pune", 16);
        } catch (AgeException e) {
            System.out.println("Exception: " + e.getMessage());
        }
    }
}

Steps to Run:

javac Main.java
java Main

Output:

Exception: Age is below 18 years

ReadUpperCase.java

Question 2: Write a Java program to read the contents of a text file (e.g., "abc.txt") and print them to the console in uppercase letters.
import java.io.File;
import java.util.Scanner;
public class ReadUpperCase {
    public static void main(String[] args) throws Exception {
        Scanner fileSc = new Scanner(new File("abc.txt"));
        while (fileSc.hasNextLine()) {
            System.out.println(fileSc.nextLine().toUpperCase());
        }
    }
}

Steps to Run:

javac ReadUpperCase.java
java ReadUpperCase

Output:

THIS IS JAVA PROGRAMMING
