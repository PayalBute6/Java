CollegeHomepage.html

Question 1: Create a responsive webpage using CSS Flexbox for a college homepage containing header, navigation, content and footer. Use appropriate Flexbox alignment and distribution properties.
<!DOCTYPE html>
<html>
<head>
    <title>College Homepage</title>
    <style>
        /* ONLY essential Flexbox CSS layout properties are used below */

        body {
            /* 1. Flexbox to stack the sections vertically */
            display: flex;
            flex-direction: column;
            
            /* Required so the body takes up the whole screen height */
            min-height: 100vh;
            margin: 0;
        }

        header {
            /* 2. Flexbox to center the header text */
            display: flex;
            justify-content: center;
            align-items: center;
        }

        nav ul {
            /* 3. Flexbox to align navigation links in a row */
            display: flex;
            justify-content: center;
            
            /* flex-wrap makes it responsive (links move to next line if screen is small) */
            flex-wrap: wrap; 
        }

        nav li {
            /* Basic spacing for the links */
            margin: 0 15px; 
            list-style: none;
        }

        main {
            /* flex: 1 makes the main area grow, pushing the footer to the bottom */
            flex: 1;
            
            /* 4. Flexbox inside the main area to center its content */
            display: flex;
            flex-direction: column;
            align-items: center;
        }

        footer {
            /* 5. Flexbox to center the footer text */
            display: flex;
            justify-content: center;
        }
    </style>
</head>
<body>

    <header>
        <h1>My College Name</h1>
    </header>

    <nav>
        <ul>
            <li><a href="#">Home</a></li>
            <li><a href="#">About Us</a></li>
            <li><a href="#">Courses</a></li>
            <li><a href="#">Contact Us</a></li>
        </ul>
    </nav>

    <main>
        <h2>Welcome to Our College</h2>
        <p>This is a responsive college homepage created using only CSS Flexbox properties.</p>
    </main>

    <footer>
        <p>Copyright 2026. All rights reserved.</p>
    </footer>

</body>
</html>

HoverEffects.html

Question 2: Create a webpage containing a button and link. Change their appearance when the mouse pointer moves over them. (Use :hover Pseudo-Class)
<!DOCTYPE html>
<html>
<head>
    <title>Hover Pseudo-Class</title>
    <style>
        /* 
           This is the normal look for our link (the <a> tag).
        */
        a {
            color: blue; /* Make the text blue */
            text-decoration: underline; /* Put a line under the text */
        }

        /* 
           The :hover part tells the browser to change the style ONLY when 
           the mouse pointer moves over the link.
        */
        a:hover {
            color: red; /* Change the text color to red */
            background-color: yellow; /* Put a yellow box behind the text */
            text-decoration: none; /* Remove the underline */
        }

        /* 
           This is the normal look for our button (the <button> tag).
        */
        button {
            background-color: lightgray; /* Make the button gray */
            color: black; /* Make the text inside the button black */
            padding: 10px; /* Add some space inside the button so it looks bigger */
        }

        /* 
           This tells the browser to change the style ONLY when 
           the mouse pointer moves over the button.
        */
        button:hover {
            background-color: green; /* Change the button color to green */
            color: white; /* Change the text color to white */
            cursor: pointer; /* Change the mouse arrow to a pointing hand */
        }
    </style>
</head>
<body>

    <h2>Hover Effects Example</h2>
    
    <!-- This creates the link on the page -->
    <p>
        Here is a link: <a href="#">Move your mouse over me!</a>
    </p>

    <br>

    <!-- This creates the button on the page -->
    <p>
        Here is a button: <button>Move your mouse over me!</button>
    </p>

</body>
</html>

ListStyles.html

Question 4: Create an unordered list of Programming Language names and apply different styles to the first and last list items.(Use :first-child and :last-child)
<!DOCTYPE html>
<html>
<head>
    <title>First and Last Child Styling</title>
    <style>
        /* 
           This is the normal look for ALL list items (the <li> tag). 
        */
        li {
            font-size: 20px;
            color: black;
            margin-bottom: 10px; /* Add some space between each item */
        }

        /* 
           The :first-child tells the browser to change the style 
           ONLY for the very FIRST item in the list.
        */
        li:first-child {
            color: red; /* Change the first item's text color to red */
            font-weight: bold; /* Make the text bold */
            background-color: yellow; /* Put a yellow box behind the text */
        }

        /* 
           The :last-child tells the browser to change the style 
           ONLY for the very LAST item in the list.
        */
        li:last-child {
            color: blue; /* Change the last item's text color to blue */
            font-style: italic; /* Make the text slanted (italic) */
            text-decoration: underline; /* Put a line under the text */
        }
    </style>
</head>
<body>

    <h2>List of Programming Languages</h2>
    
    <!-- This creates an unordered (bulleted) list -->
    <ul>
        <li>Java</li>
        <li>Python</li>
        <li>C++</li>
        <li>JavaScript</li>
        <li>Ruby</li>
    </ul>

</body>
</html>
