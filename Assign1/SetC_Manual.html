Set C - Question (a)

What is the difference between implicit type conversion and explicit type conversion in Java? Demonstration with examples.

  • Implicit Conversion (Automatic / Widening): Performed automatically by Java when converting a smaller data type to a larger data type (e.g. int to double). No data loss occurs.
  • Explicit Conversion (Manual / Narrowing): Performed manually by the programmer using the cast operator (type) when converting a larger data type to a smaller data type (e.g. double to int). Decimal digits or precision may be lost.

Code Example

public class TypeConversionDemo {
    public static void main(String[] args) {
        // 1. Implicit Conversion (int to double)
        int num = 10;
        double result = num; // Automatically converts 10 -> 10.0
        System.out.println("Implicit (int to double): " + result);

        // 2. Explicit Conversion (double to int)
        double price = 9.99;
        int roundedPrice = (int) price; // Truncates decimal .99
        System.out.println("Explicit (double to int): " + roundedPrice);
    }
}

Set C - Question (c)

What modifications are required to handle invalid user choices in a menu-driven application?

  1. Add a default: case in the switch statement: Handles invalid numeric options entered outside the expected range (e.g. choice 9 when options are 1–4).
  2. Input Validation using sc.hasNextInt(): Prevents program crashes (InputMismatchException) when a user enters non-numeric text like "abc".

Code Example

import java.util.Scanner;

public class MenuValidationDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter choice (1-4): ");

        // Check if input is a valid number
        if (sc.hasNextInt()) {
            int choice = sc.nextInt();

            switch (choice) {
                case 1: System.out.println("Option 1 selected"); break;
                case 2: System.out.println("Option 2 selected"); break;
                case 3: System.out.println("Option 3 selected"); break;
                case 4: System.out.println("Exiting..."); break;
                default: System.out.println("Invalid choice! Choose between 1 and 4."); break;
            }
        } else {
            System.out.println("Error: Invalid input! Please enter a valid number.");
        }

        sc.close();
    }
}

Set C - Question (d)

Compare the execution behavior of for, while, and do-while loops.

Feature for loop while loop do-while loop
Control Type Entry-Controlled Entry-Controlled Exit-Controlled
Condition Check Before loop execution Before loop execution After loop execution
Minimum Executions 0 times 0 times 1 time (guaranteed)
Best Use Case When exact iteration count is known When iteration depends on a condition When menu or loop must run at least once

Code Example

// 1. for loop (known count)
for (int i = 1; i <= 3; i++) {
    System.out.println("for loop count: " + i);
}

// 2. while loop (condition checked first)
int count = 1;
while (count <= 3) {
    System.out.println("while loop count: " + count);
    count++;
}

// 3. do-while loop (runs at least once)
int choice = 4;
do {
    System.out.println("do-while executes at least once!");
} while (choice != 4);

Set C - Question (e)

What modifications are required to find the second largest element in an array?

Maintain two variables first (largest) and second (second largest). Iterate through the array once in O(n) time:

Code Example

public class SecondLargestDemo {
    public static void main(String[] args) {
        int[] arr = {10, 5, 20, 8, 15};

        int first = Integer.MIN_VALUE;
        int second = Integer.MIN_VALUE;

        for (int num : arr) {
            if (num > first) {
                second = first; // Demote old max to second max
                first = num;    // Assign new max
            } else if (num > second && num != first) {
                second = num;   // Assign new second max
            }
        }

        System.out.println("Second Largest Element = " + second); // Output: 15
    }
}
