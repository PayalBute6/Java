Java String & StringBuffer - Master Exam Guide

Textbook reference featuring all syllabus methods with simple explanations, common exam traps to avoid, code examples, and expected outputs.

3 Golden Rules for Exams:
  • String Immutability: String values CANNOT be changed in memory. Calling s.concat("X") creates a new String object. If you don't assign it back (s = s.concat("X")), original s remains unchanged!
  • StringBuffer Mutability: Modifies text directly inside the same memory address. All mutator methods are synchronized (thread-safe).
  • Capacity Rule: Default StringBuffer capacity is 16 + string_length. When capacity overflows, new capacity formula is (oldCapacity * 2) + 2.

1. java.lang.String Class Methods (Main Syllabus List - 14 Methods)

# Method Signature Return Simple Description & Common Exam Trap Example Code Output
1 length() int
Counts the total number of characters in the string (including spaces and symbols).
⚠️ Common Mistake / Exam Trap: Arrays use arr.length (variable without brackets), while String uses str.length() (method with brackets)!
 String s = "Hello World";
int len = s.length();		 11
2 charAt(int index) char
Fetches the single character at the specified 0-based index position.
⚠️ Common Mistake / Exam Trap: If index is negative or >= length(), Java throws StringIndexOutOfBoundsException!
 String s = "Java";
char c = s.charAt(2);		 'v'
3 substring(int beginIndex) String
Cuts out a new string starting from beginIndex to the end of string.
⚠️ Common Mistake / Exam Trap: Original string remains unchanged because Strings are immutable.
 "HelloWorld".substring(5) "World"
4 substring(int begin, int end) String
Cuts out text from beginIndex up to endIndex - 1.
⚠️ Common Mistake / Exam Trap: endIndex is EXCLUSIVE! substring(0, 5) extracts indices 0,1,2,3,4 (length = 5 - 0 = 5).
 "HelloWorld".substring(0, 5) "Hello"
5 equals(Object obj) boolean
Compares if two strings contain the exact same text characters in exact same order (Case-Sensitive).
⚠️ Common Mistake / Exam Trap: == compares memory addresses (SCP vs Heap). .equals() compares actual text content!
 String s1 = "Java";
String s2 = new String("Java");
boolean r = s1.equals(s2);		 true
6 equalsIgnoreCase(String str) boolean
Compares string text while ignoring uppercase or lowercase differences.
⚠️ Common Mistake / Exam Trap: "JAVA".equalsIgnoreCase("java") returns true.
 String s1 = "Java";
String s2 = "JAVA";
boolean r = s1.equalsIgnoreCase(s2);		 true
7 toUpperCase() String
Converts all letters in string to uppercase.
⚠️ Common Mistake / Exam Trap: Returns a NEW string. Does not modify original string.
 "java".toUpperCase(); "JAVA"
8 toLowerCase() String
Converts all letters in string to lowercase.
⚠️ Common Mistake / Exam Trap: Does NOT alter numbers, spaces, or punctuation symbols.
 "JAVA".toLowerCase(); "java"
9 trim() String
Removes blank spaces from both beginning and end of string.
⚠️ Common Mistake / Exam Trap: Does NOT remove spaces between words in the middle! (e.g. "a b" stays "a b").
 " Hello ".trim() "Hello"
10 replace(char old, char new) String
Replaces all occurrences of old character with new character.
⚠️ Common Mistake / Exam Trap: Replaces ALL matching occurrences, not just the first one.
 "foo".replace('o', 'a') "faa"
11 contains(CharSequence s) boolean
Checks if target text exists anywhere inside the string.
⚠️ Common Mistake / Exam Trap: Does NOT accept regular expressions (regex). Case-sensitive search.
 "Hello World".contains("World") true
12 indexOf(String str) int
Finds index position of FIRST occurrence of target text.
⚠️ Common Mistake / Exam Trap: Returns -1 if target text is NOT found inside string!
 "banana".indexOf("na") 2
13 toString() String
Returns the String itself.
⚠️ Common Mistake / Exam Trap: For String objects, s.toString() simply returns s reference itself.
 String s = "Hello";
String r = s.toString();		 "Hello"
14 toCharArray() char[]
Creates a new character array char[] containing every character from the string.
⚠️ Common Mistake / Exam Trap: Modifying elements of the returned char[] array does NOT change the original String.
 String s = "JAVA";
char[] arr = s.toCharArray();		 ['J','A','V','A']
15 isEmpty() boolean
Checks if string length is 0 (i.e. "").
⚠️ Common Mistake / Exam Trap: A string containing spaces " " is NOT empty!
 "".isEmpty() true
16 isBlank() boolean
Checks if string is empty OR contains only whitespace (Java 11+).
⚠️ Common Mistake / Exam Trap: " ".isEmpty() is false, but " ".isBlank() is true.
 " ".isBlank() true
17 compareTo(String str) int
Compares two strings alphabetically based on Unicode ASCII values.
⚠️ Common Mistake / Exam Trap: Returns 0 if equal, negative if 1st precedes, positive if 1st follows.
 "apple".compareTo("banana") Negative (-1)
18 startsWith(String prefix) / endsWith(String suffix) boolean
Checks if string starts with prefix or ends with suffix.
⚠️ Common Mistake / Exam Trap: Search is case-sensitive.
 "doc.pdf".endsWith(".pdf") true
19 split(String regex) String[]
Splits string into array String[] using specified regex.
⚠️ Common Mistake / Exam Trap: Dot "." is regex special char! Use split("\\.").
 "a,b,c".split(",") ["a","b","c"]
20 concat(String str) String
Attaches str to end of string and returns a NEW String.
⚠️ Common Mistake / Exam Trap: Must reassign s = s.concat("X") to update `s`.
 "Hello".concat(" World") "Hello World"

2. java.lang.StringBuffer Class Methods (Main Syllabus List - 9 Methods)

# Method Signature Return Simple Description & Common Exam Trap Example Code Output
1 append(String str / primitives) StringBuffer
Attaches text or primitive data to end of buffer IN-PLACE.
⚠️ Common Mistake / Exam Trap: Modifies the SAME object in memory and returns reference to this.
 StringBuffer sb = new StringBuffer("Hello");
sb.append(" World");		 "Hello World"
2 insert(int offset, String str) StringBuffer
Inserts text into buffer at specified index position, pushing existing text right.
⚠️ Common Mistake / Exam Trap: Throws StringIndexOutOfBoundsException if offset is negative or > length().
 StringBuffer sb = new StringBuffer("Hello World");
sb.insert(5, ",");		 "Hello, World"
3 replace(int start, int end, String str) StringBuffer
Replaces text in range [start, end) with new string str.
⚠️ Common Mistake / Exam Trap: Replacement string str does NOT need to be same length as deleted range!
 StringBuffer sb = new StringBuffer("Hello World");
sb.replace(6, 11, "Java");		 "Hello Java"
4 delete(int start, int end) StringBuffer
Deletes character range from start index up to end - 1.
⚠️ Common Mistake / Exam Trap: end index is EXCLUSIVE! delete(5, 11) deletes indices 5,6,7,8,9,10.
 StringBuffer sb = new StringBuffer("Hello World");
sb.delete(5, 11);		 "Hello"
5 reverse() StringBuffer
Flips character order in-place (e.g. "Java" becomes "avaJ").
⚠️ Common Mistake / Exam Trap: Permanently reverses original buffer content.
 StringBuffer sb = new StringBuffer("Java");
sb.reverse();		 "avaJ"
6 length() int
Returns actual character count stored inside the buffer.
⚠️ Common Mistake / Exam Trap: length() is character count, while capacity() is total allocated buffer size!
 StringBuffer sb = new StringBuffer("Hello");
int len = sb.length();		 5
7 capacity() int
Returns total allocated memory buffer capacity size.
⚠️ Common Mistake / Exam Trap: Default capacity = 16 + initial_string_length. For "Java" (4), capacity is 16+4 = 20.
 StringBuffer sb = new StringBuffer("Java");
int cap = sb.capacity();		 20 (16 + 4)
8 charAt(int index) char
Returns character at specified 0-based index position inside buffer.
⚠️ Common Mistake / Exam Trap: Throws StringIndexOutOfBoundsException if index is invalid.
 StringBuffer sb = new StringBuffer("Java");
char c = sb.charAt(1);		 'a'
9 setCharAt(int index, char ch) void
Replaces single character at index position with new character ch.
⚠️ Common Mistake / Exam Trap: Return type is void! You CANNOT method-chain .setCharAt().
 StringBuffer sb = new StringBuffer("Java");
sb.setCharAt(0, 'Y');		 "Yava"
10 deleteCharAt(int index) StringBuffer
Deletes a single character at specified index position.
⚠️ Common Mistake / Exam Trap: Remaining characters shift left to fill gap. Length decreases by 1.
 StringBuffer sb = new StringBuffer("Java");
sb.deleteCharAt(2);		 "Jaa"
11 ensureCapacity(int minCap) void
Guarantees buffer capacity is at least minCap.
⚠️ Common Mistake / Exam Trap: If minCap > currentCapacity, new capacity formula is (oldCapacity * 2) + 2!
 StringBuffer sb = new StringBuffer();
sb.ensureCapacity(20);		 capacity = 34
12 substring(int start, int end) String
Extracts a portion of text from buffer and returns it as a String.
⚠️ Common Mistake / Exam Trap: Returns an IMMUTABLE java.lang.String, NOT a StringBuffer!
 StringBuffer sb = new StringBuffer("HelloWorld");
String s = sb.substring(0, 5);		 "Hello"

3. Important Exam Output Traces

Q1: String Immutability Trap
String s = "Java";
s.concat(" SE");
System.out.println(s);
Output: Java
Explanation: Because String is immutable, s.concat() creates a new string but s was not reassigned (s = s.concat(" SE")), so original s remains "Java".
Q2: == vs .equals() Comparison
String s1 = "Hello";
String s2 = new String("Hello");
System.out.println(s1 == s2);
System.out.println(s1.equals(s2));
Output: false then true
Explanation: s1 points to String Constant Pool, s2 points to Heap memory. == compares memory addresses (false), whereas .equals() compares actual text values (true).
Q3: StringBuffer Capacity Calculation
StringBuffer sb = new StringBuffer("Java");
System.out.println(sb.capacity());
Output: 20
Explanation: Default initial capacity is 16 + string length (4) = 20.
