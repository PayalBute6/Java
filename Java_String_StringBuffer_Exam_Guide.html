Java String & StringBuffer - Master Exam Guide

⭐ QUICK REVISION: TOP MOST IMPORTANT (IMP) EXAM METHODS

Top 10 String Class IMP Methods:
  1. length() — Total character count
  2. charAt(index) — Extract char at position
  3. substring(begin, end) — Extract sub-text (end exclusive!)
  4. equals(obj) — Compare content value
  5. concat(str) — Attach text (returns NEW string)
  6. indexOf(str) — Find position (-1 if missing)
  7. toUpperCase() / toLowerCase() — Case change
  8. trim() — Remove leading/trailing spaces
  9. replace(old, new) — Character/text replacement
  10. split(regex) — Break string into array
Top 8 StringBuffer Class IMP Methods:
  1. append(data) — Attach data in-place
  2. insert(offset, str) — Insert text at index
  3. delete(start, end) — Delete range
  4. replace(start, end, str) — Replace range
  5. reverse() — Flip order in-place
  6. capacity() — Total buffer size (16 + len)
  7. setCharAt(index, ch) — Modify single char (void)
  8. toString() — Convert to String object

1. java.lang.String Class Methods (26 Textbook Methods + Extended Reference)

# Method Signature Return Simple Description & Common Exam Trap Example Code Output
1 charAt(int index) IMP char
Fetches the single character at the specified 0-based index position.
⚠️ Common Mistake / Exam Trap: Index starts at 0. If index is negative or >= length(), Java throws StringIndexOutOfBoundsException!
 String s = "Java";
char c = s.charAt(2);		 'v'
2 length() IMP int
Counts the total number of characters in the string (including spaces and symbols).
⚠️ Common Mistake / Exam Trap: Arrays use arr.length (variable without brackets), while String uses str.length() (method with brackets)!
 String s = "Java";
int len = s.length();		 4
3 format(String format, Object... args) String
Constructs a formatted string using specifiers like %s (text), %d (integer), %.2f (decimals). (Static Method)
⚠️ Common Mistake / Exam Trap: Returns a new formatted String. Does not print directly to console by itself.
 String.format("Val: %.2f", 45.678) "Val: 45.68"
4 format(Locale l, String format, Object... args) String
Constructs a formatted string using specified Locale formatting rules.
⚠️ Common Mistake / Exam Trap: Used for internationalization formatting.
 String.format(java.util.Locale.GERMAN, "%.2f", 12.34) "12,34"
5 substring(int beginIndex) IMP String
Cuts out a new string starting from beginIndex to the end of string.
⚠️ Common Mistake / Exam Trap: Original string remains unchanged because Strings are immutable.
 "HelloWorld".substring(5) "World"
6 substring(int beginIndex, int endIndex) IMP String
Cuts out text from beginIndex up to endIndex - 1.
⚠️ Common Mistake / Exam Trap: endIndex is EXCLUSIVE! substring(0, 5) extracts indices 0,1,2,3,4 (length = 5 - 0 = 5).
 "HelloWorld".substring(0, 5) "Hello"
7 contains(CharSequence s) boolean
Checks if target text sequence exists anywhere inside the string.
⚠️ Common Mistake / Exam Trap: Does NOT accept regular expressions (regex). Search is case-sensitive.
 "Hello World".contains("World") true
8 join(CharSequence delimiter, CharSequence... elements) String
Joins multiple strings into one using a specified delimiter. (Java 8+ Static Method)
⚠️ Common Mistake / Exam Trap: Delimiter comes FIRST, followed by elements to join.
 String.join("-", "A", "B", "C") "A-B-C"
9 join(CharSequence delimiter, Iterable<? extends CharSequence> elements) String
Joins an Iterable collection (like a List<String>) using specified delimiter.
⚠️ Common Mistake / Exam Trap: Works directly with Collection objects like ArrayList of strings.
 List<String> list = Arrays.asList("X","Y");
String.join("/", list)		 "X/Y"
10 equals(Object another) IMP boolean
Compares if two strings contain the exact same text characters in exact same order (Case-Sensitive).
⚠️ Common Mistake / Exam Trap: == compares memory addresses (SCP vs Heap). .equals() compares actual text content!
 String s1 = "Java";
String s2 = new String("Java");
boolean r = s1.equals(s2);		 true
11 isEmpty() boolean
Checks if string length is 0 (i.e. "").
⚠️ Common Mistake / Exam Trap: A string containing spaces " " is NOT empty! Its length is greater than 0.
 String s = "";
boolean b = s.isEmpty();		 true
12 concat(String str) IMP String
Attaches str to end of string and returns a NEW String.
⚠️ Common Mistake / Exam Trap: Writing s.concat("X") without s = s.concat("X") leaves s unchanged!
 "Hello".concat(" World") "Hello World"
13 replace(char old, char new) IMP String
Replaces all occurrences of old character with new character.
⚠️ Common Mistake / Exam Trap: Replaces ALL matching occurrences, not just the first one.
 "foo".replace('o', 'a') "faa"
14 replace(CharSequence target, CharSequence replacement) String
Replaces each literal target sequence with replacement sequence.
⚠️ Common Mistake / Exam Trap: Treats target as literal text, NOT a regular expression.
 "bar bar".replace("bar", "foo") "foo foo"
15 trim() IMP String
Removes blank spaces from both beginning and end of string.
⚠️ Common Mistake / Exam Trap: Does NOT remove spaces between words in the middle! (e.g. "a b" stays "a b").
 " Hello ".trim() "Hello"
16 split(String regex) IMP String[]
Splits string into array String[] using specified regex delimiter.
⚠️ Common Mistake / Exam Trap: Dot "." is a special regex character! Splitting by dot requires split("\\.").
 "a,b,c".split(",") ["a","b","c"]
17 split(String regex, int limit) String[]
Splits string into array by regex up to a maximum number of limit elements.
⚠️ Common Mistake / Exam Trap: If limit is 2, splits string at first match and puts rest into 2nd element.
 "a,b,c,d".split(",", 2) ["a", "b,c,d"]
18 intern() String
Retrieves or places string reference into String Constant Pool (SCP).
⚠️ Common Mistake / Exam Trap: Allows == to return true for Heap objects if interned!
 new String("Hi").intern() SCP Reference
19 indexOf(int ch) int
Finds index position of first occurrence of character (by ASCII/Unicode int code).
⚠️ Common Mistake / Exam Trap: Returns -1 if character does not exist in string.
 "Java".indexOf('v') 2
20 indexOf(int ch, int fromIndex) int
Finds index position of character starting search from fromIndex.
⚠️ Common Mistake / Exam Trap: Ignores matches that occur before fromIndex.
 "banana".indexOf('a', 2) 3
21 indexOf(String substring) IMP int
Finds index position of FIRST occurrence of target substring.
⚠️ Common Mistake / Exam Trap: Returns -1 if target substring is NOT found.
 "banana".indexOf("na") 2
22 indexOf(String substring, int fromIndex) int
Finds index position of substring starting search from fromIndex.
⚠️ Common Mistake / Exam Trap: Starts scanning forward from fromIndex.
 "banana".indexOf("na", 3) 4
23 toLowerCase() IMP String
Converts all letters in string to lowercase using default locale.
⚠️ Common Mistake / Exam Trap: Does NOT alter numbers, spaces, or punctuation symbols.
 "JAVA".toLowerCase(); "java"
24 toLowerCase(Locale l) String
Converts all letters to lowercase using rules of specified Locale.
⚠️ Common Mistake / Exam Trap: Used for language-specific casing rules.
 "TITLE".toLowerCase(java.util.Locale.ENGLISH) "title"
25 toUpperCase() IMP String
Converts all letters in string to uppercase using default locale.
⚠️ Common Mistake / Exam Trap: Returns a NEW string. Does not modify original string.
 "java".toUpperCase(); "JAVA"
26 toUpperCase(Locale l) String
Converts all letters to uppercase using specified Locale rules.
⚠️ Common Mistake / Exam Trap: Used for international uppercase conversion.
 "title".toUpperCase(java.util.Locale.ENGLISH) "TITLE"
27 toCharArray() char[]
Creates a new character array char[] containing every character from string.
⚠️ Common Mistake / Exam Trap: Modifying the array does NOT modify original string.
 "JAVA".toCharArray() ['J','A','V','A']
28 getBytes() byte[]
Encodes string into numeric byte values (ASCII/UTF-8 byte codes).
⚠️ Common Mistake / Exam Trap: Letter 'A' becomes 65.
 "ABC".getBytes() [65, 66, 67]
29 equalsIgnoreCase(String str) boolean
Compares string text while ignoring uppercase or lowercase differences.
⚠️ Common Mistake / Exam Trap: "JAVA".equalsIgnoreCase("java") returns true.
 "Java".equalsIgnoreCase("JAVA") true
30 compareTo(String str) int
Compares two strings alphabetically based on Unicode ASCII values.
⚠️ Common Mistake / Exam Trap: Returns 0 if equal, negative if 1st precedes, positive if 1st follows.
 "apple".compareTo("banana") Negative (-1)
31 startsWith(String prefix) / endsWith(String suffix) boolean
Checks if string starts with prefix or ends with suffix.
⚠️ Common Mistake / Exam Trap: Search is case-sensitive.
 "doc.pdf".endsWith(".pdf") true
32 replaceAll(String regex, String rep) / replaceFirst(String regex, String rep) String
Replaces regex pattern matches with replacement string.
⚠️ Common Mistake / Exam Trap: Uses Regex matching.
 "a1b2c3".replaceAll("\\d", "#") "a#b#c#"
33 String.valueOf(Object obj) String
Safely converts primitives (int, double, boolean) or objects to String. (Static)
⚠️ Common Mistake / Exam Trap: valueOf(null) returns text "null".
 String.valueOf(100) "100"

2. java.lang.StringBuffer Class Methods (16 Textbook Methods)

# Method Signature Return Simple Description & Common Exam Trap Example Code Output
1 append(String str / primitives) IMP StringBuffer
Attaches text or primitive data to end of buffer IN-PLACE.
⚠️ Common Mistake / Exam Trap: Modifies the SAME object in memory and returns reference to this.
 StringBuffer sb = new StringBuffer("Hello");
sb.append(" World");		 "Hello World"
2 reverse() IMP StringBuffer
Flips character order in-place (e.g. "Java" becomes "avaJ").
⚠️ Common Mistake / Exam Trap: Permanently reverses original buffer content.
 StringBuffer sb = new StringBuffer("Java");
sb.reverse();		 "avaJ"
3 delete(int start, int end) IMP StringBuffer
Deletes character range from start index up to end - 1.
⚠️ Common Mistake / Exam Trap: end index is EXCLUSIVE! delete(5, 11) deletes indices 5,6,7,8,9,10.
 StringBuffer sb = new StringBuffer("Hello World");
sb.delete(5, 11);		 "Hello"
4 insert(int offset, String str) IMP StringBuffer
Inserts text into buffer at specified index position, pushing existing text right.
⚠️ Common Mistake / Exam Trap: Throws StringIndexOutOfBoundsException if offset is negative or > length().
 StringBuffer sb = new StringBuffer("Hello World");
sb.insert(5, ",");		 "Hello, World"
5 replace(int start, int end, String str) IMP StringBuffer
Replaces text in range [start, end) with new string str.
⚠️ Common Mistake / Exam Trap: Replacement string str does NOT need to be same length as deleted range!
 StringBuffer sb = new StringBuffer("Hello World");
sb.replace(6, 11, "Java");		 "Hello Java"
6 capacity() IMP int
Returns total allocated memory buffer capacity size.
⚠️ Common Mistake / Exam Trap: Default capacity = 16 + initial_string_length. For "Java" (4), capacity is 16+4 = 20.
 StringBuffer sb = new StringBuffer("Java");
int cap = sb.capacity();		 20 (16 + 4)
7 charAt(int index) char
Returns character at specified 0-based index position inside buffer.
⚠️ Common Mistake / Exam Trap: Throws StringIndexOutOfBoundsException if index is invalid.
 StringBuffer sb = new StringBuffer("Java");
char c = sb.charAt(1);		 'a'
8 ensureCapacity(int minCap) void
Guarantees buffer capacity is at least minCap.
⚠️ Common Mistake / Exam Trap: If minCap > currentCapacity, new capacity formula is (oldCapacity * 2) + 2!
 StringBuffer sb = new StringBuffer();
sb.ensureCapacity(20);		 capacity = 34
9 getChars(int srcBegin, int srcEnd, char[] dst, int dstBegin) void
Copies characters from range [srcBegin, srcEnd) into destination char array dst starting at dstBegin.
⚠️ Common Mistake / Exam Trap: dst array must be large enough to store copied characters.
 StringBuffer sb = new StringBuffer("Hello World");
char[] d = new char[5];
sb.getChars(6, 11, d, 0);		 d = ['W','o','r','l','d']
10 indexOf(String str) int
Finds index position of FIRST occurrence of substring inside buffer.
⚠️ Common Mistake / Exam Trap: Returns -1 if substring is not found.
 StringBuffer sb = new StringBuffer("banana");
int idx = sb.indexOf("na");		 2
11 lastIndexOf(String str) int
Finds index position of LAST occurrence of substring inside buffer.
⚠️ Common Mistake / Exam Trap: Searches backward from end of buffer. Returns -1 if missing.
 StringBuffer sb = new StringBuffer("banana");
int idx = sb.lastIndexOf("na");		 4
12 length() int
Returns actual character count stored inside the buffer.
⚠️ Common Mistake / Exam Trap: length() is character count, while capacity() is total allocated buffer size!
 StringBuffer sb = new StringBuffer("Hello");
int len = sb.length();		 5
13 setCharAt(int index, char ch) IMP void
Replaces single character at index position with new character ch.
⚠️ Common Mistake / Exam Trap: Return type is void! You CANNOT method-chain .setCharAt().
 StringBuffer sb = new StringBuffer("Java");
sb.setCharAt(0, 'Y');		 "Yava"
14 setLength(int newLength) void
Changes length of character sequence in buffer.
⚠️ Common Mistake / Exam Trap: If newLength < length(), text is truncated! If larger, padded with null '\u0000' chars.
 StringBuffer sb = new StringBuffer("Hello");
sb.setLength(2);		 "He"
15 substring(int start, int end) String
Extracts a portion of text from buffer and returns it as a String.
⚠️ Common Mistake / Exam Trap: Returns an IMMUTABLE java.lang.String, NOT a StringBuffer!
 StringBuffer sb = new StringBuffer("HelloWorld");
String s = sb.substring(0, 5);		 "Hello"
16 toString() IMP String
Converts current `StringBuffer` into a standard immutable `String`.
⚠️ Common Mistake / Exam Trap: Creates a brand new `String` object on Heap memory.
 StringBuffer sb = new StringBuffer("Java");
String s = sb.toString();		 "Java"
