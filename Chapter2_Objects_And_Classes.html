Unit 2.1

2.1 Introduction

2.1.1 Java and Object-Oriented Programming

Java is an Object-Oriented Programming (OOP) language. In Java, objects and classes are the basic building blocks of Object-Oriented Programming. Everything that we represent in Java is associated with classes and objects.

In Object-Oriented Programming, we represent real-world entities using objects. For example:

  • Student
  • Employee
  • Car
  • Bank Account
  • Customer
  • Book

All of these can be represented as objects in Java.

State and Behavior

Every real-world object generally has two important characteristics:

1. State

State represents the data or characteristics of an object.

For example, a Car can have state attributes such as:

  • Color
  • Model
  • Brand
  • Price
  • Speed

Similarly, a Student can have state attributes such as Roll number, Name, Age, and Course.

2. Behavior

Behavior represents the actions or operations that an object can perform.

For example, a Car can Perform actions like Start, Stop, Accelerate, Brake. A Student can perform actions like Study, AttendLecture, WriteExam.

💡 Key Principle:
State represents what an object HAS, whereas behavior represents what an object DOES.

Object in Java

Definition: A real-world entity that has state and behavior is known as an object.
Simple Definition for Examination: An object is an instance of a class.

For example, consider a cat:

  • State: Color, Name, Age
  • Behavior: Walking, Eating, Sleeping

Class in Java

Definition: A class is a template or blueprint that describes the states and behaviors supported by objects of its type.
Class Student │ ┌───────┴───────┐ │ │ Object Object Student 1 Student 2

Difference Between Class and Object

Class Object
Class is a blueprint/template. Object is an instance of a class.
It defines state and behavior. It represents actual state and behavior values.
Objects are created from a class. Object is created using the class template.
Example: Student Example: s1, s2
Logical representation (occupies no heap memory for data) Real/actual representation (occupies heap memory)
Car Class │ ┌─────────┼─────────┐ │ │ │ Car1 Car2 Car3

Unit 2.2

2.2 Defining Your Own Classes

Java allows programmers to create their own classes according to application requirements. A class contains:

  • Data members / variables
  • Methods
  • Constructors

General Syntax of a Class

class ClassName
{
    // Fields declaration
    accessSpecifier dataType variable;

    // Methods declaration
    accessSpecifier returnType methodName()
    {
        // body of method
    }
}

Textbook Example:

class Student
{
    int id;
    String name;

    void display()
    {
        System.out.println(id);
        System.out.println(name);
    }
}

Simple `Hello` Class Example:

class Hello
{
    public void show()
    {
        System.out.println("Hello");
    }
}

// Calling method via object:
Hello h = new Hello();
h.show();

Methods in Java

A method is a collection of statements grouped together to perform a particular task. Methods avoid redundant code and promote reusability.

General Syntax of Method:

return-type method-name(parameter-list)
{
    // body of method
}

Example Program:

class Example
{
    int add(int a, int b)
    {
        return a + b;
    }

    public static void main(String args[])
    {
        Example obj = new Example();
        int result = obj.add(10, 20);
        System.out.println(result);
    }
}
Output:
30

Method Characteristics:

  • Represents the behavior of an object.
  • Contains a collection of statements.
  • Can accept parameters and return values (or use void).
  • Called using an object reference for instance methods.

2.2.1 Creating Objects

An object is created using the new keyword.

ClassName objectName = new ClassName();

Three Steps Involved in Object Creation

  1. Declaration: A reference variable is declared (`Student s1;`). Object is not created yet.
  2. Instantiation: The `new` keyword allocates memory for the object (`new Student()`).
  3. Initialization: The constructor initializes the newly created object.
Declaration ──► Student s1; │ Instantiation ──► new Student(); (Heap Memory Allocated) │ Initialization──► Constructor invoked
⭐ Important Distinction:
In Student s1 = new Student();:
- Student is the Class.
- s1 is the Reference Variable.
- new Student() creates the actual Object in heap memory.

2.2.2 Accessing Class Members

Members are accessed using the dot (.) operator (syntax: objectName.memberName;).

class Student
{
    String name;
    int age;

    void display()
    {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

public class Main
{
    public static void main(String[] args)
    {
        Student s = new Student();
        s.name = "Rahul";
        s.age = 20;

        s.display();
    }
}
Output:
Name: Rahul
Age: 20

Unit 2.3

2.3 Access Specifiers

Java provides 4 access specifiers to restrict visibility and enforce encapsulation:

2.3.1 Private Access Modifier

The private modifier provides the highest degree of restriction. Accessible only inside the class in which it is declared.

Accessor and Mutator Methods (Getters & Setters)

  • Accessor (Getter): Reads/accesses the private variable value (e.g. public int getSalary() { return salary; }).
  • Mutator (Setter): Modifies/changes the private variable value safely (e.g. public void setSalary(int salary) { this.salary = salary; }).
class Student
{
    private String name;
    private int age;

    public void setName(String name) { this.name = name; }
    public void setAge(int age) { this.age = age; }

    public void display()
    {
        System.out.println("My name is " + name);
        System.out.println("I am " + age + " years old");
    }
}

public class TestPrivate
{
    public static void main(String[] args)
    {
        Student s = new Student();
        s.setName("abc");
        s.setAge(20);
        s.display();
    }
}
Output:
My name is abc
I am 20 years old

2.3.2 Default Access Modifier

When no modifier is specified, Java assigns default (package-level) access. Accessible by classes in the same package.

2.3.3 Protected Access Modifier

Accessible within the same class, same package, and by subclasses in other packages through inheritance.

2.3.4 Public Access Modifier

Provides the widest visibility. Accessible from anywhere across all packages.

Access Specifier Comparison Table

Access Modifier Same Class Same Package Subclass (Diff Pkg) Outside Package
private ✓ ✗ ✗ ✗
default ✓ ✓ ✗ ✗
protected ✓ ✓ ✓ (via inheritance) ✗
public ✓ ✓ ✓ ✓

Unit 2.4

2.4 Array of Objects

An array of objects stores references to objects of a particular class rather than primitive values directly.

Writing Employee emp[] = new Employee[3]; only creates an array container holding 3 null references. Objects must be created separately:

Initially (Array of references): emp ──► [ null , null , null ] After Object Instantiation: emp ──► [ Employee Object 1 , Employee Object 2 , Employee Object 3 ]

Complete Program Example:

class Employee
{
    int id;
    String name;

    public void setData(int id, String name)
    {
        this.id = id;
        this.name = name;
    }

    public void display()
    {
        System.out.println("Employee id: " + this.id);
        System.out.println("Employee name: " + this.name);
    }

    public static void main(String[] args)
    {
        Employee emp[] = new Employee[3];

        emp[0] = new Employee();
        emp[1] = new Employee();
        emp[2] = new Employee();

        emp[0].setData(1, "Amit");
        emp[1].setData(2, "Akash");
        emp[2].setData(3, "Akbar");

        emp[0].display();
        emp[1].display();
        emp[2].display();
    }
}
Output:
Employee id: 1
Employee name: Amit

Employee id: 2
Employee name: Akash

Employee id: 3
Employee name: Akbar

Unit 2.5

2.5 Constructors and Overloading Constructors

A constructor is a special method used to initialize an object automatically when it is created using new.

Constructor vs Method Comparison Table

Constructor Method
Used to initialize an object. Used to perform a specific task/action.
Must have the exact same name as the class. Can have any valid identifier name.
Has no return type (not even void). Must specify a return type (or void).
Automatically invoked during object creation. Invoked explicitly via object or class reference.

Textbook Constructor Rules

  1. Constructor name must match class name exactly.
  2. Constructor cannot have a return type (adding void turns it into a method).
  3. Constructor access modifier can be private, protected, or public.

Constructor Overloading

Defining multiple constructors in the same class with different parameter lists.

class Student
{
    int rollNo;
    String name;

    // 1. Default constructor
    Student()
    {
        rollNo = 0;
        name = "Unknown";
    }

    // 2. Single-parameter constructor
    Student(int rollNo)
    {
        this.rollNo = rollNo;
        name = "Unknown";
    }

    // 3. Two-parameter constructor
    Student(int rollNo, String name)
    {
        this.rollNo = rollNo;
        this.name = name;
    }

    void display()
    {
        System.out.println("Roll No: " + rollNo + ", Name: " + name);
    }

    public static void main(String[] args)
    {
        Student s1 = new Student();
        Student s2 = new Student(101);
        Student s3 = new Student(102, "Rahul");

        s1.display();
        s2.display();
        s3.display();
    }
}
Output:
Roll No: 0, Name: Unknown
Roll No: 101, Name: Unknown
Roll No: 102, Name: Rahul

Unit 2.6

2.6 'this' Keyword & Static Members

The `this` Keyword

Refers to the current object instance. Differentiates instance variables from parameters (`this.roll = roll`) and invokes constructors (`this()`).

Static Members

  • Static Field: Single shared variable copy across all objects.
  • Static Method: Invoked without object (`ClassName.method()`). Can access static data directly.
  • Static Block: Executed once when class is loaded into JVM memory.

Unit 2.7

2.7 Predefined Classes (Object, String, StringBuffer)

Object Class: Root parent class of all classes (`toString()`, `equals()`, `hashCode()`, `getClass()`).

String vs StringBuffer: String is immutable (SCP storage), StringBuffer is mutable (Heap memory, synchronized).

String.format(): Uses format specifiers (`%s`, `%d`, `%f`, `%b`).

Unit 2.8

2.8 Packages & Wrapper Classes

Packages: Groups related classes (`package mypack;`, `import mypack.*;`, `javac -d .`).

Wrapper Classes: Object representation of primitives (`int` → `Integer`, Autoboxing & Unboxing, `Integer.parseInt()`).
