2.1 Defining Your Own Classes

Concept Definition

A Class is a user-defined blueprint or prototype from which objects are created. It represents the set of properties (state) and methods (behavior) that are common to all objects of one type.

An Object is a basic runtime entity and an instance of a class that occupies memory.

Syntax

class <ClassName> {
    // Member variables (Fields / State)
    <data_type> variable1;
    
    // Member methods (Behavior)
    <return_type> methodName(<parameters>) {
        // body of method
    }
}

Key Exam Concepts

  • Instantiation: Memory is allocated only when an object is instantiated using the new operator: <ClassName> obj = new <ClassName>();.
  • Dot Operator (.): Used to access instance variables and invoke member methods on an object (obj.variable, obj.method()).

Minimal Code Example

class Student {
    int rollNo;
    String name;

    void display() {
        System.out.println("Roll No: " + rollNo + ", Name: " + name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s1 = new Student(); // Object creation
        s1.rollNo = 101;
        s1.name = "Alice";
        s1.display();
    }
}

2.2 Access Specifiers

Java provides four access levels to implement encapsulation and control visibility across classes and packages.

Visibility Comparison Table

Access Specifier Same Class Same Package Subclass Same Package Non-Subclass Different Package Subclass Different Package Non-Subclass
private Yes No No No No
default (no keyword) Yes Yes Yes No No
protected Yes Yes Yes Yes (via inheritance) No
public Yes Yes Yes Yes Yes

Key Exam Points

  • private: Provides the highest level of restriction; accessible only within its declaring class. Used for data hiding.
  • default (Package-Private): Applied automatically when no modifier is declared; accessible anywhere within the same package.
  • protected: Accessible within the same package and by child classes in different packages through inheritance.
  • public: Universally accessible across all packages.

2.3 Array of Objects

Concept Definition

An Array of Objects is an array that stores references to instances of a class rather than storing primitive values directly.

Memory Layout

  1. Declaring Employee[] emp = new Employee[3]; only creates 3 reference slots in memory initialized to null.
  2. Each object instance must be explicitly allocated using new before accessing its members; otherwise, a NullPointerException occurs.
emp (Array Reference) ──► [ null , null , null ] │ emp[0] = new Employee(...) ▼ [ Object Data ]

Minimal Code Example

class Employee {
    int id;
    String name;

    Employee(int id, String name) {
        this.id = id;
        this.name = name;
    }

    void printData() {
        System.out.println("ID: " + id + " | Name: " + name);
    }
}

public class ArrayDemo {
    public static void main(String[] args) {
        // Step 1: Declare and allocate array of references
        Employee[] empList = new Employee[2];

        // Step 2: Instantiate individual elements
        empList[0] = new Employee(1, "John");
        empList[1] = new Employee(2, "Sarah");

        // Step 3: Traverse
        for (Employee e : empList) {
            e.printData();
        }
    }
}

2.4 Constructors & Constructor Overloading

Concept Definition

A Constructor is a special member method invoked automatically when an object is created. Its primary purpose is to initialize instance variables.

Rules of Constructors

  • Name must be identical to the class name.
  • Must not have an explicit return type (not even void).
  • Cannot be abstract, static, final, or synchronized.

Types of Constructors

  1. Default Constructor: Provided automatically by the compiler if no explicit constructor is defined (initializes fields to default values like 0, null, false).
  2. No-Argument Constructor: Explicitly written constructor with no parameters.
  3. Parameterized Constructor: Accepts arguments to initialize custom values for fields.

Constructor Overloading

Defining multiple constructors within the same class with different parameter lists (differing in data types, number of parameters, or parameter sequence).

Minimal Code Example

class Box {
    double width, height, depth;

    // No-arg constructor
    Box() {
        width = height = depth = 1.0;
    }

    // Single-parameter constructor (Cube)
    Box(double len) {
        width = height = depth = len;
    }

    // Parameterized constructor
    Box(double w, double h, double d) {
        width = w;
        height = h;
        depth = d;
    }

    double volume() {
        return width * height * depth;
    }
}

2.5 Use of `this`, `static` Block, Static Fields, and Static Methods

1. The `this` Keyword

this is a reference variable that refers to the current invoking object.

  • Variable Shadowing Resolution: Differentiates instance variables from local parameters: this.x = x;.
  • Constructor Chaining: Invokes another constructor in the same class: this(arg1, arg2); (must be the first line of the constructor).
  • Passing the Current Object: Passes this as an argument to other methods or constructors.

2. The `static` Keyword

Belongs to the class rather than individual instances. Only one copy is shared among all objects.

  • Static Variable: Class-level variable shared by all instances.
  • Static Method: Can be invoked directly via class name (ClassName.method()) without instantiating an object. Cannot access non-static (instance) variables or use this/super directly.
  • Static Block: A block of code executed only once when the class is loaded into JVM memory, before constructors or the main() method run.

Minimal Code Example

class Counter {
    int id;               // Instance variable
    static int count = 0; // Static variable

    // Static Initialization Block
    static {
        System.out.println("Static Block: Class loaded.");
    }

    Counter(int id) {
        this.id = id;     // 'this' resolves variable shadowing
        count++;
    }

    static void displayTotal() { // Static method
        System.out.println("Total instances created: " + count);
    }
}

public class StaticDemo {
    public static void main(String[] args) {
        Counter c1 = new Counter(101);
        Counter c2 = new Counter(102);
        Counter.displayTotal(); // Invoked without object reference
    }
}

2.6 Predefined Classes

2.6.1 The `Object` Class

java.lang.Object is the root superclass of all classes in Java. Every class directly or indirectly inherits from it.

Core Methods of `Object` Class

Method Signature Description
toString() public String toString() Returns a textual representation of the object (default: ClassName@HexHashCode).
equals() public boolean equals(Object obj) Compares memory references by default (==). Must be overridden for content equality.
hashCode() public int hashCode() Returns an integer hash code value for the object used in hashing structures.
getClass() public final Class<?> getClass() Returns the runtime class representation of the object.

Minimal Code Example

class Point {
    int x, y;

    Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    @Override
    public String toString() {
        return "(" + x + ", " + y + ")";
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Point p = (Point) obj;
        return this.x == p.x && this.y == p.y;
    }

    @Override
    public int hashCode() {
        return 31 * x + y;
    }
}

2.6.2 `String` vs `StringBuffer` & `String.format()`

Comparison: `String` vs `StringBuffer`

Feature `String` `StringBuffer`
Mutability Immutable (cannot be modified after creation). Mutable (modifiable in place).
Storage Location String Constant Pool (SCP) & Heap. Heap Memory only.
Thread Safety Thread-safe by design due to immutability. Thread-safe (methods are synchronized).
Performance Slower when performing repeated concatenations. Faster for frequent string modifications.
Modification Methods concat(), substring(), replace() append(), insert(), delete(), reverse()

Formatting String Data using `format()`

String.format() produces formatted output without printing directly:

  • %s: String
  • %d: Integer
  • %f: Floating-point number (e.g., %.2f for two decimal places)
  • %n: Platform-independent newline

Minimal Code Example

public class StringDemo {
    public static void main(String[] args) {
        // String Immutability
        String str = "Hello";
        str.concat(" World");
        System.out.println("String: " + str); // Outputs: Hello

        // StringBuffer Mutability
        StringBuffer sb = new StringBuffer("Hello");
        sb.append(" World");
        System.out.println("StringBuffer: " + sb); // Outputs: Hello World

        // Formatting
        String report = String.format("Item: %s | Price: $%.2f | Units: %d", "Book", 19.995, 3);
        System.out.println(report); // Outputs: Item: Book | Price: $20.00 | Units: 3
    }
}

2.7 Creating, Accessing, and Using Packages

Concept Definition

A Package is a namespace mechanism that groups related classes, interfaces, and sub-packages.

Advantages

  • Prevents naming collisions.
  • Provides modularity and structured code organization.
  • Enforces access control (protected and default access modifiers).

Syntax & Usage

1. Declaring a Package: Must be the first non-comment statement in a .java file:

package mypack;

public class Calculator {
    public int add(int a, int b) { return a + b; }
}

2. Compiling Packages via Terminal:

javac -d . Calculator.java

(The -d . option creates the directory structure automatically).

3. Importing & Using Packages:

// Option A: Specific class import
import mypack.Calculator;

// Option B: All classes in package
import mypack.*;

// Option C: Fully Qualified Name (no import required)
mypack.Calculator calc = new mypack.Calculator();

2.8 Wrapper Classes

Concept Definition

Wrapper Classes provide an object representation of the 8 primitive data types within the java.lang package.

Primitive to Wrapper Mapping

Primitive TypeWrapper Class
byteByte
shortShort
intInteger
longLong
floatFloat
doubleDouble
charCharacter
booleanBoolean

Key Operations

  • Autoboxing: Automatic conversion of a primitive type into its corresponding wrapper object by the compiler.
  • Unboxing: Automatic conversion of a wrapper object back into its primitive type.
  • String Parsing Methods: Static utility methods used to convert Strings into primitives:
    • Integer.parseInt("123")
    • Double.parseDouble("45.67")
    • Boolean.parseBoolean("true")

Minimal Code Example

public class WrapperDemo {
    public static void main(String[] args) {
        // Autoboxing: int -> Integer
        int a = 25;
        Integer boxed = a; 

        // Unboxing: Integer -> int
        int unboxed = boxed; 

        // Parsing String to Primitive
        String strNum = "450";
        int parsed = Integer.parseInt(strNum);

        // Utility method
        String binaryStr = Integer.toBinaryString(10); // "1010"

        System.out.println("Boxed: " + boxed + " | Parsed: " + parsed + " | Binary: " + binaryStr);
    }
}

High-Yield Viva & Exam Questions

1. What is the difference between shallow copy and deep copy?

A shallow copy duplicates object references, meaning changes affect both copies. A deep copy creates entirely independent copies of both the object and the reference fields it points to.

2. Can we overload the `main()` method in Java?

Yes, we can overload main() by providing different parameter lists, but the JVM will only execute the standard entry signature public static void main(String[] args).

3. Why is `String` immutable in Java?

For security (handling network/file connections), synchronization/thread-safety, caching in the String Constant Pool (SCP), and consistent hashcode generation for hash-based collections.

4. What happens if a constructor is made `private`?

Objects of that class cannot be instantiated from outside the class. This pattern is primarily used to implement the Singleton Design Pattern or utility classes with only static methods.
