Unit 2.1

2.1 Defining Your Own Classes

2.1.1 Class

A class is a blueprint or template used to create objects. It defines the data and behavior that objects of the class will have.

A class generally contains two main components:

  1. Data Members / Instance Variables – represent the properties or attributes of an object.
  2. Methods – represent the behavior or actions performed by an object.

Example Class Definition:

class Student 
{
    int rollNo;
    String name;

    void displayInfo() 
    {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
    }
}

Here:

  • Student → Class
  • rollNo and name → Data members (Instance variables)
  • displayInfo() → Method
🏠 Real-World Analogy:
A house plan is a blueprint. Multiple physical houses can be constructed using the exact same plan.

Class → Blueprint
Object → Actual house created from the blueprint

2.1.2 Object

An object is an instance of a class. It represents an actual real-world entity created using the class template.

Objects are created dynamically in heap memory using the new keyword.

Syntax for Object Creation:

ClassName objectName = new ClassName();

Example:

Student s1 = new Student();

Breakdown:

  • Student → Class name
  • s1 → Reference variable name
  • new → Keyword that allocates memory for the object
  • Student() → Constructor call to initialize the object

After object creation, members are accessed using the dot (.) operator:

s1.rollNo = 101;
s1.name = "Alice";

s1.displayInfo();
📌 Important Points to Remember:
  • A class is a blueprint; an object is an instance of a class.
  • Multiple objects can be created from a single class definition.
  • Objects are created using the new keyword.
  • Object members are accessed using the dot (.) operator.

Unit 2.2

2.2 Access Specifiers

An access specifier (or access modifier) controls the accessibility (visibility) of variables, methods, and classes across packages and classes.

Java provides four access levels:

2.2.1 private

The private access specifier allows a member to be accessed only within the same class.

class Student 
{
    private int rollNo = 101;

    void display() 
    {
        System.out.println(rollNo); // Accessible inside same class
    }
}
> private → Accessible only within the same class. (Used for Data Hiding).

2.2.2 default

When no access modifier is specified, the member has default access (also called package-private access). Accessible within the same package.

class Student 
{
    int rollNo = 101; // Default access
}
> default → Accessible within the same package.

2.2.3 protected

The protected access specifier allows access within the same package and by subclasses in another package.

class Student 
{
    protected int rollNo = 101;
}
> protected → Same package + subclasses in another package.

2.2.4 public

The public access specifier provides the widest accessibility. A public member can be accessed from any class and package.

class Student 
{
    public int rollNo = 101;
}
> public → Accessible from anywhere.

Access Specifier Comparison Table

Access Specifier Same Class Same Package Subclass (Diff Package) Everywhere
private ✓ ✗ ✗ ✗
default ✓ ✓ ✗ ✗
protected ✓ ✓ ✓ ✗
public ✓ ✓ ✓ ✓
💡 Easy Memory Trick:
private → Class
default → Package
protected → Package + Child
public → Everywhere

Unit 2.3

2.3 Array of Objects

An array of objects is an array used to store references to multiple objects of the same class.

Creating an array of objects requires two distinct steps:

Step 1: Create the array of references

Student[] students = new Student[3]; // Allocates memory for 3 reference variables (all null)

Step 2: Create objects for each element

students[0] = new Student();
students[1] = new Student();
students[2] = new Student();

Complete Code Example:

class Student 
{
    int roll;

    Student(int r) 
    {
        roll = r;
    }

    void display() 
    {
        System.out.println("Roll No: " + roll);
    }

    public static void main(String[] args) 
    {
        // Step 1: Create array
        Student[] students = new Student[3];

        // Step 2: Create objects
        students[0] = new Student(101);
        students[1] = new Student(102);
        students[2] = new Student(103);

        // Displaying using loop
        for(int i = 0; i < students.length; i++) 
        {
            students[i].display();
        }
    }
}
Output:
Roll No: 101
Roll No: 102
Roll No: 103
📌 Important Points:
  • An array of objects stores object references.
  • The array container and individual objects must be created separately.
  • Individual objects are accessed using an index (e.g. students[0]).
  • A loop (for or for-each) is used to traverse all objects.

Unit 2.4

2.4 Constructors

A constructor is a special block of code used to initialize an object when it is created.

Rules of Constructors:

  1. A constructor has the exact same name as the class.
  2. A constructor has no return type, not even void.
  3. It is automatically executed when an object is created using new.
  4. It is mainly used to initialize instance variables.

Example:

class Student 
{
    int roll;

    // Constructor
    Student() 
    {
        roll = 101;
    }

    void display() 
    {
        System.out.println("Roll No: " + roll);
    }

    public static void main(String[] args) 
    {
        Student s = new Student(); // Constructor automatically called here
        s.display();
    }
}
Output:
Roll No: 101

Types of Constructors

1. No-Argument Constructor

A constructor that accepts no parameters.

Student() 
{
    roll = 101;
}

2. Parameterized Constructor

A constructor that accepts parameters to set custom values.

Student(int r) 
{
    roll = r;
}

// Object Creation:
Student s = new Student(101);

Constructor Overloading

Constructor overloading means defining multiple constructors in the same class with different parameter lists (different number or types of parameters).

Example Program:

class Box 
{
    Box() 
    {
        System.out.println("Default Constructor");
    }

    Box(int x) 
    {
        System.out.println("One Parameter: " + x);
    }

    Box(int x, int y) 
    {
        System.out.println("Two Parameters: " + x + ", " + y);
    }

    public static void main(String[] args) 
    {
        Box b1 = new Box();
        Box b2 = new Box(10);
        Box b3 = new Box(10, 20);
    }
}
Output:
Default Constructor
One Parameter: 10
Two Parameters: 10, 20
📌 Important Point: Constructors must have different parameter lists (different types, number, or sequence of parameters) for overloading to occur.

Unit 2.5

2.5 'this' Keyword & Static Members

The `this` Keyword

The this keyword is a reference variable that refers to the current object.

A common use is to differentiate between an instance variable and a local parameter having the same name:

class Student 
{
    int roll;

    Student(int roll) 
    {
        this.roll = roll; // 'this.roll' = instance variable, 'roll' = parameter
    }
}

`this()` Constructor Call (Constructor Chaining)

this() is used to call another constructor of the same class.

class Student 
{
    Student() 
    {
        this(101); // Calls Student(int roll)
    }

    Student(int roll) 
    {
        System.out.println("Roll No: " + roll);
    }

    public static void main(String[] args) 
    {
        Student s = new Student();
    }
}
Output:
Roll No: 101
📌 Important Point: this() must be the very first statement inside a constructor.

Static Members

The static keyword indicates that a member belongs to the class itself rather than individual objects.

1. Static Field (Variable)

A static field is shared by all objects of a class. Only one common copy exists in memory.

class Student 
{
    int roll;                 // Unique per object
    static String college = "ABC College"; // Shared by all objects
}

2. Static Method

A static method belongs to the class and can be invoked without creating an object (`ClassName.methodName()`).

class Student 
{
    static void display() 
    {
        System.out.println("Hello Student");
    }

    public static void main(String[] args) 
    {
        Student.display(); // Called directly using class name
    }
}
Output:
Hello Student

3. Static Block

A static block executes once when the class is initialized/loaded into memory by JVM before main().

class Student 
{
    static 
    {
        System.out.println("Static Block Executed");
    }

    public static void main(String[] args) 
    {
        System.out.println("Main Method Executed");
    }
}
Output:
Static Block Executed
Main Method Executed
📌 Use: Static blocks are mainly used for initializing static data members.

Unit 2.6

2.6 Predefined Classes

Java provides many predefined classes as part of its standard API library (`java.lang` package).

2.6.1 Object Class

java.lang.Object is the root parent class of all Java classes.

Important Methods of Object Class:

1. toString(): Returns a String representation of an object.

class Student 
{
    int roll = 101;
    String name = "Ram";

    public String toString() 
    {
        return roll + " " + name;
    }

    public static void main(String[] args) 
    {
        Student s = new Student();
        System.out.println(s.toString()); // Output: 101 Ram
    }
}

Note: If not overridden, default representation is ClassName@HashCode (e.g. Student@5acf9800).

2. equals(Object obj): Used to check if two objects are equal. Overridden to compare object data.

class Student 
{
    int roll;
    Student(int r) { roll = r; }

    public boolean equals(Object obj) 
    {
        Student s = (Student)obj;
        return roll == s.roll;
    }
}

3. hashCode(): Returns an integer hash code value for an object (used in hash tables like HashMap).

Rule: If two objects are equal according to equals(), they must return the same hash code.

4. getClass(): Returns the runtime class information of an object.

Student s = new Student();
System.out.println(s.getClass()); // Output: class Student

2.6.2 String Class & StringBuffer Class

1. String Class

String is a predefined class used to represent a sequence of characters. Strings are Immutable (cannot be modified after creation). 
String s = "Hello";
s = s + " World"; // Creates a NEW String object in String Constant Pool

2. StringBuffer Class

StringBuffer is a predefined class used to store a Mutable (modifiable) sequence of characters. 
StringBuffer sb = new StringBuffer("Hello");
sb.append(" World"); // Modifies original buffer directly
System.out.println(sb); // Output: Hello World

Difference Between String and StringBuffer

Feature String StringBuffer
Nature Immutable (Cannot be changed) Mutable (Can be changed)
Modification Creates a new String object Modifies existing buffer directly
Frequent Changes Less suitable (causes memory overhead) More suitable (efficient)
Thread Safety Thread-safe due to immutability Thread-safe (Synchronized methods)

Formatting String Data using `format()`

The String.format() method creates a formatted String using format specifiers.

class FormatDemo 
{
    public static void main(String[] args) 
    {
        String name = "Ram";
        int age = 22;

        String result = String.format("Name: %s, Age: %d", name, age);
        System.out.println(result); // Output: Name: Ram, Age: 22
    }
}

Common Format Specifiers Table:

Format SpecifierMeaning
%sString
%dInteger
%fFloating-point number (e.g. %.2f for 2 decimals)
%cCharacter
%bBoolean

Unit 2.7

2.7 Creating, Accessing and Using Packages

A package is a namespace used to group related classes, interfaces, and sub-packages (similar to a folder in a file system).

Advantages of Packages:

  1. Organizes related classes logically.
  2. Prevents naming conflicts (two classes with the same name in different packages).
  3. Provides access protection (default and protected levels).
  4. Makes code maintainable and reusable.

Creating a Package:

Use the package keyword at the very top of the file.

// File: Calculator.java
package mypack;

public class Calculator 
{
    public int add(int a, int b) 
    {
        return a + b;
    }
}

Accessing a Package:

Use the import keyword.

// File: Main.java
import mypack.Calculator; // Import specific class

class Main 
{
    public static void main(String[] args) 
    {
        Calculator c = new Calculator();
        System.out.println("Result = " + c.add(10, 20)); // Output: 30
    }
}

Package Compilation via Terminal:

javac -d . Calculator.java
java Main

The -d . option tells compiler to create package directory structure automatically in current folder.

Unit 2.8

2.8 Wrapper Classes

A wrapper class is a class that represents/wraps a primitive data type into an object.

Primitive Data Types and Wrapper Classes:

Primitive TypeWrapper Class
byteByte
shortShort
intInteger
longLong
floatFloat
doubleDouble
charCharacter
booleanBoolean

Why are Wrapper Classes Required?

  1. Collections: Java collection framework (`ArrayList`, `HashMap`) works only with objects (`ArrayList<Integer>`).
  2. Parsing & Conversion: Methods to convert String data to primitive numbers (`Integer.parseInt("123")`).
  3. Utility Methods: Helper functions like `Character.isDigit('5')`.

Autoboxing

Autoboxing is the automatic conversion of a primitive type into its corresponding wrapper object. 
int num = 50;
Integer obj = num; // int -> Integer (Autoboxing)

Unboxing

Unboxing is the automatic conversion of a wrapper object into its corresponding primitive type. 
Integer obj = 50;
int num = obj; // Integer -> int (Unboxing)
