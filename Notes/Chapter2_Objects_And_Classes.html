CHAPTER 2 – OBJECTS AND CLASSES

2.1 Defining Your Own Classes & Objects

1. Introduction to Class and Object

Java is an Object-Oriented Programming (OOP) language. In Java, programs are constructed using classes and objects. A class represents the blueprint or template, while an object is the real-world instance created from that blueprint.

An object encapsulates two key characteristics:

  • State (Data): Represented by instance variables or fields (e.g., rollNo, name, marks).
  • Behavior (Actions): Represented by methods or functions (e.g., display(), calculateResult()).

2. Class vs Object Blueprint Concept

STUDENT CLASS (Blueprint) ------------------------------ | rollNo | | name | | display() | ------------------------------ / \ / \ ↓ ↓ Object s1 Object s2 --------- --------- rollNo = 101 rollNo = 102 name = "Rahul" name = "Priya"

3. General Syntax of a Class

class Student
{
    // 1. Instance Variables (Fields)
    int rollNo;
    String name;

    // 2. Methods (Behavior)
    void display()
    {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
    }
}

4. Object Creation Process

An object in Java is created using the new keyword in two steps or a single combined statement:

// Option A: Two-step approach
Student s1;           // Step 1: Reference variable declaration (holds null)
s1 = new Student();   // Step 2: Instantiation in Heap memory & constructor call

// Option B: Single-step approach (Most common)
Student s1 = new Student();

Members of an object are accessed using the dot (.) operator (e.g., s1.rollNo = 101; s1.display();).

5. Complete Java Code Example

class Student
{
    int rollNo;
    String name;

    void display()
    {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
    }
    public static void main(String[] args)
    {
        Student s1 = new Student();  // Create object s1
        s1.rollNo = 101;
        s1.name = "Rahul";
        s1.display();                // Display s1 details

        Student s2 = new Student();  // Create object s2
        s2.rollNo = 102;
        s2.name = "Priya";
        s2.display();                // Display s2 details
    }
}
Output:
Roll No: 101, Name: Rahul
Roll No: 102, Name: Priya

Difference Between Class and Object

Class Object
A class is a blueprint or template for creating objects. An object is an instance of a class.
It defines the data and behavior of objects. It represents the actual data and behavior of a particular instance.
A class contains variables and methods. An object contains actual values for the instance variables.
A class itself does not represent a particular entity. An object represents a particular entity.
A class is declared using the class keyword. An object is generally created using the new keyword.
Example: class Student Example: Student s1 = new Student();
One class can be used to create many objects. Each object has its own instance data.

2.2 Access Specifiers in Java

Definition: Access specifiers (or access modifiers) are keywords in Java that control the visibility, scope, and accessibility of classes, variables, methods, and constructors across different packages and classes.

An access specifier answers the question: "From where can I access this member?"

1. Four Access Levels in Java

Access Specifier Accessibility Scope
private Accessible only within the same class where declared.
default (package-private) Accessible only within the same package (when no modifier is specified).
protected Accessible within the same package and by subclasses in other packages (via inheritance).
public Accessible from everywhere across all packages.

2. Master Access Location Matrix

Access Specifier Same Class Same Package Subclass in Other Package Non-subclass in Other Package
private Yes No No No
default Yes Yes No No
protected Yes Yes Yes Limited Access
public Yes Yes Yes Yes

3. Detailed Case Breakdown

  • Case 1 (Same Class): All 4 modifiers (public, protected, default, private) are directly accessible.
  • Case 2 (Same Package): public, protected, and default are accessible. Only private is inaccessible.
  • Case 3 (Subclass in Diff Package): public and protected (through inheritance) are accessible. default and private are inaccessible.
  • Case 4 (Non-subclass in Diff Package): Only public members are directly accessible.

4. Complete Java Code Example

class AccessDemo
{
    public int publicVar = 10;
    protected int protectedVar = 20;
    int defaultVar = 30;            // Package-private
    private int privateVar = 40;

    void display()
    {
        System.out.println("Public: " + publicVar);
        System.out.println("Protected: " + protectedVar);
        System.out.println("Default: " + defaultVar);
        System.out.println("Private: " + privateVar);
    }
}

public class Main
{
    public static void main(String[] args)
    {
        AccessDemo demo = new AccessDemo();
        demo.display();
    }
}
Output:
Public: 10
Protected: 20
Default: 30
Private: 40

2.3 Array of Objects

An array of objects is an array that stores references to multiple objects of the same class.

Syntax:

ClassName[] arrayName = new ClassName[size];

Example:

Student[] students = new Student[5];
Definition: An array of objects in Java is an array that stores reference variables pointing to objects of a class rather than holding raw primitive data values.

Array of objects stores references to objects, not the objects themselves directly.

In Java, an array of objects is an array that stores references to objects of a class.

Just like an ordinary array stores multiple values of the same data type, an array of objects can store multiple objects of the same class.

1. How Array of Objects Works

Creating an array of objects is a two-phase process:

  1. Declare & Allocate Reference Array: Employee emp[] = new Employee[3]; creates an array of 3 reference slots initialized to null.
  2. Instantiate Individual Objects: emp[0] = new Employee(); allocates actual object memory in Heap for each array element.
Phase 1: Reference Array Created emp ──► [ null , null , null ] Phase 2: Individual Objects Instantiated emp ──► [ Employee Object 0 ] , [ Employee Object 1 ] , [ Employee Object 2 ]

2. Complete Java Code Example

class Student
{
    int rollNo;
    String name;

    void display()
    {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
    }
}

public class ArrayObject
{
    public static void main(String args[])
    {
        Student[] students = new Student[3];

        students[0] = new Student();
        students[1] = new Student();
        students[2] = new Student();

        students[0].rollNo = 1;
        students[0].name = "Radha";

        students[1].rollNo = 2;
        students[1].name = "Riya";

        students[2].rollNo = 3;
        students[2].name = "Sneha";

        students[0].display();
        students[1].display();
        students[2].display();
    }
}

Name: Radha

2.4 Constructors and Constructor Overloading

Definition: A constructor is a special member function of a class used to initialize newly created objects. It has the exact same name as the class and has no return type. It is automatically executed when an object is instantiated using the new keyword.

1. Characteristics of Constructors

  • Must have the same name as the class.
  • Has no return type (not even void).
  • Executed automatically during object creation via new.
  • Mainly used to initialize instance variables of an object.
  • Can be overloaded within the same class.
class Student
{
    int rollNo;
    String name;

    // Default constructor
    Student()
    {
        rollNo = 0;
        name = "Unknown";
    }

    void display()
    {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
    }
}

public class Test
{
    public static void main(String args[])
    {
        Student s = new Student(); // uses default constructor
        s.display();
    }
}
Output:
0 Unknown

2. Constructor vs Method

Constructor Method
A constructor is used to initialize an object. A method is used to perform an operation or define behavior.
Constructor name must be same as the class name. Method name can be any valid identifier.
Constructor does not have a return type, not even void. A method has a return type or void.
Constructor is called automatically when an object is created using new. A method is called explicitly using its name.
Constructor is executed when the object is created. Method is executed whenever it is called.
Constructors can be overloaded. Methods can also be overloaded.
Constructor cannot be inherited. Methods can be inherited, depending on access and class relationship.
Constructor is mainly used for initialization. Method is mainly used for performing a task/operation.

3. Types of Constructors

A. Default (Parameterless) Constructor

A constructor that accepts no arguments, initializing fields to default or preset values.

class Student
{
    int roll;
    String name;

    Student()
    {
        roll = 0;
        name = "Unknown";
    }
}

B. Parameterized Constructor

A constructor accepting parameters to initialize objects with specific custom values.

class Student
{
    int roll;
    String name;

    Student(int r, String n)
    {
        roll = r;
        name = n;
    }
}

4. Constructor Overloading

Definition: Defining multiple constructors in the same class with different parameter lists (differing in number, type, or order of parameters) is known as constructor overloading.

Valid vs Invalid Overloading Rules:

Constructor Signatures Status Reason
Student() and Student(int r) and Student(int r, String n) ✅ Valid Different number of parameters.
Demo(int x) and Demo(double x) ✅ Valid Different parameter data types.
Student(int r) and Student(int x) ❌ Invalid Parameter names differ, but data types are identical (int)!

5. Complete Java Code Example

class Student
{
    int roll;
    String name;

    // Parameterless Constructor
    Student()
    {
        roll = 0;
        name = "Unknown";
    }

    // Parameterized Constructor
    Student(int r, String n)
    {
        roll = r;
        name = n;
    }

    void display()
    {
        System.out.println("Roll No: " + roll);
        System.out.println("Name: " + name);
    }

    public static void main(String[] args)
    {
        Student s1 = new Student();              // Calls parameterless constructor
        Student s2 = new Student(101, "Rahul");   // Calls parameterized constructor

        s1.display();
        s2.display();
    }
}
Output:
Roll No: 0, Name: Unknown
Roll No: 101, Name: Rahul

2.6 'this' Keyword, Static Fields, Static Methods and Static Blocks

1. The `this` Keyword

Definition: this is a special reference variable in Java that refers to the current object instance. In simple words: "this" means "the current object on which a method or constructor is operating."

The primary use of this is to differentiate instance variables from constructor parameters when they share the exact same names (variable shadowing):

Student(int roll, String name)
{
    this.roll = roll;  
    // this.roll → current ob   ject's field | roll → constructor parameter
    
    this.name = name;  
    // this.name → current object's field | name → constructor parameter
}

2. Three Primary Uses of `this` Keyword

  1. Refers to Current Object Field: Differentiates instance variables from parameter variables with identical names.
  2. Constructor Chaining (`this()`): Invokes another constructor within the same class.
  3. Passing Current Object: Passes `this` reference as an argument to another method.

Constructor Chaining using `this()`

class Student
{
    int roll;
    String name;

    Student()
    {
        this(0, "Unknown"); // Invokes Student(int, String) parameterized constructor!
    }

    Student(int roll, String name)
    {
        this.roll = roll;
        this.name = name;
    }
}
⚠️ Important Rule: When this() is used to call another constructor, it MUST be the first statement inside the constructor!

3. Static Members (Fields, Methods & Blocks)

The static keyword denotes members that belong to the class itself rather than individual object instances.

3.1 Static Field (Class Variable)

A variable declared with static is shared across all instances of the class. Only one single memory copy exists for the entire class in Heap/Metaspace.
Instance Variables (Separate memory per object): s1 ──► roll = 101, name = "Prashant" s2 ──► roll = 102, name = "Rahul" Static Variable (Single shared memory across all objects): Student Class │ static String college │ "XYZ College" / \ s1 s2

3.2 Static Method

A method declared with static belongs to the class and can be invoked directly using the Class Name: Student.changeCollege("XYZ College"); without creating an object.
⚠️ Important Rule: A static method can directly access ONLY static data and static methods. It CANNOT directly access non-static instance variables because instance variables depend on an object context!

3.3 Static Block

A static { ... } block executes ONCE when the class is loaded into JVM memory, even before the main() method runs or any object is created. Used for initializing static variables.

4. Complete Program (`this` + Static Field + Static Method + Static Block)

class Student
{
    int roll;
    String name;

    static String college = "ABC College";

    // Constructor using 'this' keyword
    Student(int roll, String name)
    {
        this.roll = roll;
        this.name = name;
    }

    // Static method
    static void changeCollege()
    {
        college = "XYZ College";
    }

    void display()
    {
        System.out.println("Roll No: " + roll);
        System.out.println("Name: " + name);
        System.out.println("College: " + college);
    }

    // Static block
    static
    {
        System.out.println("Static block executed.");
    }
}

public class ThisStaticExample
{
    public static void main(String[] args)
    {
        Student.changeCollege();

        Student s1 = new Student(101, "Prashant");
        Student s2 = new Student(102, "Rahul");

        s1.display();
        s2.display();
    }
}
Output:
Static block executed.
101 Prashant XYZ College
102 Rahul XYZ College

Step-by-Step Program Execution Breakdown:

  1. Step 1 (Class Load & Static Block): When JVM loads Student class, the static block executes immediately, printing "Static block executed.".
  2. Step 2 (Static Method Call): Student.changeCollege(); changes shared college from "ABC College" to "XYZ College".
  3. Step 3 (Object s1 Creation): new Student(101, "Prashant") invokes constructor; this.roll = roll sets s1.roll = 101 and s1.name = "Prashant".
  4. Step 4 (Object s2 Creation): new Student(102, "Rahul") sets s2.roll = 102 and s2.name = "Rahul".
  5. Step 5 (Display): Both s1.display() and s2.display() print "XYZ College" because college is a shared static variable.

Instance vs Static Members

Instance Members Static Members
Belong to the object/instance of the class. Belong to the class itself.
Each object gets its own copy of instance variables. Only one common copy is associated with the class.
Created when an object is created. Created/available when the class is loaded.
Accessed using the object reference. Can be accessed using the class name.
Instance variables can have different values for different objects. Static variable has a common value shared by all objects.
Instance methods can directly access instance members. Static methods can directly access only static members.
Instance members are declared without `static`. Static members are declared using the `static` keyword.
Example: name, rollNo, display() Example: college, count, show()

2.6 Predefined Classes

2.6.1 Object Class (java.lang.Object)

Object is the most basic class in Java. Every other class automatically extends it, so every object gets basic abilities like converting to a string, comparing, and knowing its type.

Method Description
toString() Returns a readable text version of the object. By default it shows "ClassName@hashcode", but you can override it to show anything you want.
equals(Object obj) Checks whether two objects are the same. By default it checks if they are the exact same instance; you can override it to compare their contents.
hashCode() Returns a number used for hash‑based collections. The default is based on the object's address, but you can override it.
getClass() Returns the runtime class (type) of the object.

1. toString()

Purpose: Convert an object to a string representation.

class Student {
    int rollNo;
    String name;

    Student(int r, String n) {
        rollNo = r;
        name = n;
    }

    @Override
    public String toString() {
        return rollNo + " " + name;
    }
}

public class Test {
    public static void main(String[] args) {
        Student s = new Student(1, "Radha");
        System.out.println(s.toString());
    }
}
Output:
1 Radha

Explanation: s.toString() calls the overridden method, which returns the concatenated roll number and name.

toString() → converts/represents an object as a String

2. equals(Object obj)

Purpose: Compares two objects for equality.

class Student {
    int rollNo;
    String name;

    Student(int r, String n) {
        rollNo = r;
        name = n;
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Student other = (Student) obj;
        return rollNo == other.rollNo && name.equals(other.name);
    }
}

public class Test {
    public static void main(String[] args) {
        Student s1 = new Student(1, "Radha");
        Student s2 = new Student(1, "Radha");
        System.out.println(s1.equals(s2));
    }
}
Output:
true

Explanation: The overridden equals compares roll numbers and names of the two Student objects.

equals() → compares objects

Difference Between String and StringBuffer

String StringBuffer
Immutable (contents cannot change). Mutable (contents can be changed).
Once a String object is created, its content cannot be changed. Content of a StringBuffer object can be changed.
Any modification creates a new String object. Modification takes place in the same object.
String is suitable when the value does not change frequently. StringBuffer is suitable when the value changes frequently.
String operations may create more objects. StringBuffer generally avoids creating a new object for every modification.
String is not synchronized. StringBuffer methods are synchronized and therefore thread-safe.
String is generally preferred for fixed text. StringBuffer is useful for repeated modifications, especially in multithreaded environments.

2.7 Creating, Accessing and Using Packages

A package is a container in Java that groups related classes, interfaces, and sub-packages together under a unique common namespace.

1. Benefits of Packages

  • Avoid Name Conflicts: Allows classes in different packages to share identical names (e.g. college.Student vs school.Student).
  • Organize Code: Logically organizes classes into directory folder structures.
  • Access Control: Enforces visibility protection across package boundaries using protected and default access.
  • Reusability: Classes defined inside packages can be easily imported into other projects.

2. Types of Packages

  • Built-in (System) Packages: Standard packages provided by Java API (e.g., java.lang, java.util, java.io, java.net).
    • No.PackagePurposeExamples of Classes
    1java.langBasic Java classesString, Object, Math, System, Integer
    2java.utilUtility classes and collectionsScanner, ArrayList, HashMap, Date

package mypack;

public class Greeting
{
    public void showMsg()
    {

2.8 Wrapper Classes

A wrapper class is a predefined class in java.lang that wraps a primitive data type into an object, allowing primitives to be treated as objects.

1. Primitive Types and Wrapper Classes

Primitive Data Type Wrapper Class Conversion Method (Object → Primitive)
byte Byte byteValue()
short Short shortValue()
int Integer intValue()
long Long longValue()
float Float floatValue()
double Double doubleValue()
char Character charValue()
boolean Boolean booleanValue()

2. Autoboxing, Unboxing and Parsing

Wrapping (Primitive → Object): Converting a basic primitive data type (like int) into an Object (like Integer).

int a = 20;
Integer i = Integer.valueOf(a);

Unwrapping (Object → Primitive): Extracting the raw primitive value out from inside a wrapper object.

Integer a = Integer.valueOf(20);
int i = a.intValue();

Autoboxing: Java automatically converts a primitive into a wrapper object for you.

int a = 20;
Integer i = a; // The compiler handles this automatically

Unboxing: Java automatically pulls the primitive value out of a wrapper object for you.

Integer i = 20;
int a = i; // The compiler handles this automatically

Parsing (String → Primitive): Converting a text String (like "150") into an actual number (like 150) so you can do math with it.

int n = Integer.parseInt("150");
double d = Double.parseDouble("99.99");

Converting Number → String: Converting a primitive number into text format.

int n = 100;
String s = Integer.toString(n);

3. String Parsing Methods

int num = Integer.parseInt("150");        // String -> int primitive
double val = Double.parseDouble("99.99"); // String -> double primitive
String str = Integer.toString(200);       // int primitive -> String

4. Complete Java Code Example

class WrapperDemo
{
    public static void main(String[] args)
    {
        int primitiveVal = 50;

        // Autoboxing (Primitive -> Object)
        Integer obj = Integer.valueOf(primitiveVal);
        System.out.println("Wrapper Object: " + obj);

        // Unboxing (Object -> Primitive)
        int backToPrimitive = obj.intValue();
        System.out.println("Primitive Value: " + backToPrimitive);

        // String parsing
        int parsedInt = Integer.parseInt("100");
        System.out.println("Parsed Sum: " + (parsedInt + 50));
    }
}
Output:
Wrapper Object: 50
Primitive Value: 50
Parsed Sum: 150
